# 二维小波变换 DWT/IDWT 交互式演示系统

## 功能概述

基于 PyWavelets + NumPy + matplotlib + Tkinter 实现的二维离散小波变换交互式演示系统，支持：

- **小波基**: Haar、Db2 (Daubechies 2)、Sym2 (Symlet 2)
- **多层分解**: 支持1-5层小波分解与重构
- **系数可视化**: 多子带系数展示、对数增强显示
- **能量分析**: 各子带能量分布统计与可视化
- **阈值去噪**: 软/硬阈值去噪，支持自动阈值计算
- **交互界面**: Tkinter GUI 集成 matplotlib 绘图

## 安装依赖

```bash
pip install numpy PyWavelets matplotlib Pillow
```

## 运行程序

```bash
python dwt_demo.py
```

## 操作说明

### 1. 加载图像
- **加载示例**: 生成带噪声的正弦测试图像（256×256）
- **加载图片**: 支持 PNG、JPG、BMP、TIFF 等格式，自动转为灰度并缩放

### 2. DWT 分解
1. 选择小波基：Haar / Db2 / Sym2
2. 设置分解层数：1-5层
3. 点击「执行DWT分解」

**显示内容**:
- 原始图像
- 小波系数全景图（对数增强）
- 各子带系数（cA, cH, cV, cD）
- 能量分布柱状图
- 系数幅值直方图（对数坐标）
- 重构结果占位

### 3. IDWT 重构
点击「执行IDWT重构」，状态栏显示：
- MSE (均方误差)
- PSNR (峰值信噪比)

### 4. 阈值去噪
1. 选择阈值类型：
   - **Soft (软阈值)**: 平滑去噪，保留细节
   - **Hard (硬阈值)**: 锐化去噪，边缘保留好
2. 调节阈值大小（0.01-1.0）
3. 点击「应用去噪」

**自动阈值**:
基于通用阈值公式 `T = σ√(2logN)` 自动计算最优阈值，其中：
- σ 为噪声标准差估计（中值绝对偏差）
- N 为细节系数数量

## 技术实现

### 核心函数
- `pywt.wavedec2()`: 二维多层小波分解
- `pywt.waverec2()`: 二维小波重构
- `pywt.threshold()`: 系数阈值处理
- `pywt.coeffs_to_array()`: 系数矩阵转换

### 小波基特性

| 小波基 | 长度 | 消失矩 | 特性 |
|--------|------|--------|------|
| Haar | 2 | 1 | 最简单，正交，不连续 |
| Db2 | 4 | 2 | 紧支集，正交，平滑性好 |
| Sym2 | 4 | 2 | 接近对称，相位失真小 |

### 能量守恒
小波变换满足 Parseval 恒等式，变换前后能量守恒：
```
Σ|f(x,y)|² = Σ|cA|² + Σ|cH|² + Σ|cV|² + Σ|cD|²
```

## 常见问题

**Q: 为什么系数图大部分是黑色的？**
A: 小波系数具有稀疏性，大部分细节系数接近零，使用对数增强显示便于观察。

**Q: 软阈值和硬阈值有什么区别？**
A: 硬阈值直接置零小于阈值的系数；软阈值对大于阈值的系数做收缩，结果更平滑。

**Q: 分解层数越多越好吗？**
A: 层数越多，频率分辨率越高，但空间分辨率越低。图像去噪通常使用2-3层。
