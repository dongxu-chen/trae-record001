# 流程图自动布局工具

基于 Vue3 + Fabric.js + Dagre + D3-Force 开发的Web端流程图自动布局工具。

## 功能特性

- 🎨 **多种节点类型** - 支持矩形、圆形、菱形、平行四边形、文档等多种流程图节点
- 🔗 **A*寻路布线** - 拖拽节点后自动调整连线路径，采用A*寻路算法智能避开节点，减少拐点
- 📐 **自动对齐吸附** - 拖拽时自动对齐最近节点的边缘和中心线，显示蓝色辅助线
- 📊 **自动布局** - 支持层次布局（Dagre）、力导向布局（D3-Force）、环形布局
- 📁 **节点分组** - 支持节点分组、折叠/展开功能，折叠后子节点占位，其他节点重新布局
- 🧵 **Web Worker** - 力导向布局使用Web Worker计算，避免阻塞主线程
- 📑 **多页签支持** - 一个窗口管理多个流程图，支持页签切换、新增、删除
- 📥 **文件导入** - 支持导入Draw.io (.drawio/.xml) 和 Visio (.vsdx) 格式文件
- 💾 **导出功能** - 支持导出为SVG、PNG、JSON格式
- 🖱️ **交互操作** - 支持节点拖拽、连线创建、缩放、属性编辑等
- 🎯 **属性面板** - 可编辑节点和连线的样式属性

## 技术栈

- **Vue 3** - 渐进式JavaScript框架
- **Fabric.js** - 强大的Canvas绘图库
- **Dagre** - 层次布局算法库
- **D3-Force** - 力导向布局算法
- **A* 寻路算法** - 智能正交布线
- **Web Worker** - 后台计算力导向布局
- **JSZip** - 解析Visio (.vsdx) 文件
- **Vite** - 下一代前端构建工具

## 使用说明

### 添加节点

1. 点击工具栏的节点按钮（矩形、圆形、菱形等）
2. 或点击右侧面板中的节点图标

### 连接节点

1. 鼠标悬停在节点上，会显示四个连接点（蓝色圆点）
2. 从一个连接点拖拽到另一个节点即可创建连线

### 自动对齐吸附

1. 拖拽节点时，会自动检测与其他节点的边缘和中心线对齐
2. 显示蓝色虚线辅助线
3. 10像素范围内自动吸附
4. 可通过工具栏的"对齐吸附"开关启用/禁用

### 自动布局

点击工具栏的布局按钮：
- **层次布局** - 自上而下的层级结构，适合流程图
- **力导向布局** - 基于物理仿真的布局，Web Worker后台计算
- **环形布局** - 节点均匀分布在圆周上

### 节点分组

1. 按住Shift键选择多个节点
2. 点击工具栏的"分组"按钮
3. 双击分组或点击分组右上角的按钮可折叠/展开
4. 折叠后分组作为占位节点参与布局，子节点自动恢复位置

### 多页签管理

- 点击页签栏右侧的"+"按钮新建流程图
- 点击页签切换不同流程图
- 点击页签上的"×"关闭流程图（至少保留一个）
- 页签名称可自动识别导入的文件名

### 文件导入

点击工具栏的"📁 导入"按钮，支持：
- **.drawio / .xml** - Draw.io格式文件
- **.vsdx** - Visio格式文件
- 导入后自动在新页签中打开

### 导出

点击工具栏的导出按钮：
- **SVG** - 矢量图形格式，可无损缩放
- **PNG** - 位图格式，适合预览和分享
- **JSON** - 数据格式，可用于保存和恢复

### 快捷键

- `Delete` - 删除选中的节点或连线
- `Ctrl + 滚轮` - 缩放画布

## 核心算法说明

### 正交布线算法

- 基于节点边界计算连接点
- 生成多条候选路径并评估
- 考虑路径长度和节点遮挡
- 选择最优的正交路径

### 层次布局（Dagre）

- 自动计算节点层级
- 最小化边交叉
- 均匀分布节点
- 支持TB、LR、BT、RL四种方向

### 力导向布局（D3-Force）

- 节点间斥力模拟
- 连线张力模拟
- 中心点引力
- 碰撞检测避免重叠
