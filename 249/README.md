# 地铁客流预测系统

基于Prophet + GBDT组合模型的智能客流预测平台，使用Python + Flask + ECharts实现。

## 功能特性

1. **客流预测**：使用Prophet + GBDT组合模型预测未来1小时各站点进站/出站客流
2. **节假日特殊拟合**：Prophet模型内置中国节假日参数，支持节假日特殊拟合
3. **置信区间**：输出95%置信区间的预测结果
4. **实时客流预警**：当前客流超过预测置信区间上界时自动触发预警
5. **快慢线分析**：客流的短期波动和长期趋势分离，自动识别异常节点
6. **调度辅助建议**：根据OD预测结果推荐加开区间车、调整发车间隔
7. **OD矩阵热力图**：支持按需加载，只渲染Top N热门客流路径
8. **临时事件模拟调整**：直接调整预测结果（无需重训练），支持自定义修正系数
9. **历史趋势分析**：展示近7天历史客流趋势
10. **多站点对比**：各站点客流对比分析

## 使用说明

### 1. 客流预测
- 选择要查看的站点
- 选择预测时长（1/6/12/24小时）
- 点击"开始预测"按钮

### 2. 置信区间展示
预测图表中阴影区域表示95%置信区间，展示预测结果的不确定性范围。

### 3. OD矩阵热力图
- 横轴：到达站点
- 纵轴：出发站点
- 颜色深浅：客流量大小
- 鼠标悬停查看具体数值

### 4. OD矩阵热力图（按需加载）
- 选择要显示的路径数量（Top 20/30/50/全部）
- 点击"加载数据"按钮按需渲染
- 下方显示热门路径排行榜

### 5. 临时事件模拟调整
- 选择受影响的站点（可多选）
- 设置**进站修正系数**（0 = 完全关闭，0.5 = 减半，1.5 = 增加50%等）
- 设置**出站修正系数**
- 可选：勾选"影响相邻站点"，设置邻站影响系数
- 点击"应用事件调整"按钮，系统直接在预测结果上应用调整（无需重训练）
- 点击"重置"恢复原始预测

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/predict` | GET | 获取客流预测结果 |

| `/api/stations` | GET | 获取所有站点列表 |
| `/api/station_stats` | GET | 获取各站点统计数据 |

## 模型改进说明

### Prophet节假日特殊拟合
- 内置中国法定节假日数据（春节、国庆、五一等）
- `holidays_prior_scale=10.0` 增强节假日影响权重
- 节假日前后各1天也纳入影响范围（lower_window=-1, upper_window=1）
- 新增周末季节性分量（condition_name='is_weekend'）
- 新增小时级精细季节性（fourier_order=8）

### 事件调整机制
- 采用预测后修正方式，无需重新训练模型
- 支持自定义修正系数，灵活模拟各种场景：
  - 0.0 = 站点完全关闭（客流为0）
  - 0.0 ~ 1.0 = 客流减少（如疫情、限流）
  - 1.0 ~ 3.0 = 客流增加（如大型活动）
- 支持相邻站点联动影响（如封站后客流分流）

### 实时预警机制
- 基于预测置信区间上界进行阈值判断
- 超过105%触发中等预警，超过120%触发高级预警
- 每30秒自动轮询检测，实时推送预警信息

### 快慢线分析算法
- **趋势分解**：移动平均法分离长期趋势（24小时窗口）
- **短期波动**：原始客流减去趋势分量得到波动分量
- **异常检测**：2σ原则（Z-Score > 2 或 < -2）识别异常点
- **模式分类**：波动性评分 > 50 为快线模式，否则为慢线模式

### 调度建议生成
- **发车间隔**：基于峰值客流动态计算（2-8分钟分级）
- **区间车识别**：连续高客流区间聚类分析
- **大站快车**：Top站点覆盖分析

## 技术栈

- **后端**：Python + Flask
- **预测模型**：Prophet + LightGBM (GBDT)
- **前端可视化**：ECharts
- **数据处理**：Pandas + NumPy
