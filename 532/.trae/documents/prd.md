## 1. 产品概述

代码差异可视化工具（CodeDiff Viewer）是一个 Web 端专业级代码对比平台，帮助开发者直观地查看两个代码版本之间的差异。支持并排对比、语法高亮、差异着色、目录树对比、代码折叠和差异跳转，大幅提升代码审查和版本对比的效率。

- 目标用户：软件开发者、代码审查人员、团队技术负责人
- 核心价值：将枯燥的文本 diff 转化为直观的可视化对比体验，减少代码审查中的认知负担

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 开发者 | 直接访问 | 输入代码、查看差异、导航跳转 |

### 2.2 功能模块

1. **差异对比页**：并排 Monaco Editor 差异视图、差异着色、语法高亮、代码折叠、差异跳转导航
2. **目录树对比页**：双版本文件树并排展示、差异文件标记、点击文件切换对比内容
3. **输入面板**：支持粘贴代码或上传文件/目录作为输入源

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 差异对比页 | Monaco Diff Editor | 并排展示两个版本代码，差异行着色标注（新增绿色、删除红色、修改黄色），支持语法高亮 |
| 差异对比页 | 差异导航栏 | 显示差异总数和当前位置，提供上一个/下一个差异跳转按钮，快捷键支持 |
| 差异对比页 | 代码折叠 | 按函数/类/块折叠未变更代码段，聚焦差异区域 |
| 差异对比页 | 语言选择器 | 选择代码语言以启用对应语法高亮 |
| 目录树对比页 | 双栏文件树 | 左侧旧版本文件树，右侧新版本文件树，差异文件用颜色标记（新增/删除/修改） |
| 目录树对比页 | 文件切换 | 点击文件树中的文件，右侧自动加载该文件的 diff 视图 |
| 输入面板 | 代码输入区 | 两个文本框分别输入旧版和新版代码，或上传文件/目录 |
| 顶部导航 | 模式切换 | 切换「代码对比」和「目录树对比」两种模式 |

## 3. 核心流程

1. 用户进入首页，选择对比模式（代码对比 / 目录树对比）
2. **代码对比模式**：用户在左右输入框粘贴代码，选择语言，点击「对比」按钮，下方展示 Monaco Diff Editor 并排差异视图
3. **目录树对比模式**：用户上传旧版和新版目录（或粘贴文件内容），左侧展示双栏文件树，差异文件高亮标记，点击文件查看具体 diff
4. 差异视图中可使用导航栏跳转差异，使用折叠功能收起未变更区域

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色主题为主（IDE 风格），主色 `#1e1e2e`（背景），强调色 `#7c3aed`（紫色调操作按钮）
- **差异着色**：新增行 `#1a3a2a`（绿底）+ `#4ade80`（绿色标记），删除行 `#3a1a1a`（红底）+ `#f87171`（红色标记），修改行 `#3a3a1a`（黄底）+ `#facc15`（黄色标记）
- **字体**：代码区使用 `JetBrains Mono`，UI 区使用 `IBM Plex Sans`
- **布局**：顶部工具栏 + 左侧文件树（可折叠）+ 右侧主编辑区
- **按钮风格**：圆角微凸，hover 时发光效果
- **图标风格**：Lucide 图标库，线条风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 差异对比页 | 顶部工具栏 | 语言选择下拉、对比模式切换、主题切换、差异统计摘要 |
| 差异对比页 | Monaco Diff Editor | 双栏并排编辑器、行号差异标记、折叠控件、迷你地图 |
| 差异对比页 | 差异导航栏 | 浮动在编辑器底部，显示「3/12 差异」，左右箭头按钮 |
| 目录树对比页 | 双栏文件树 | 左右各一个树形控件，文件夹可展开，文件图标按类型显示，差异文件彩色标记 |
| 目录树对比页 | 文件详情区 | 选中文件后右侧展示 diff 视图 |
| 输入面板 | 代码输入区 | 两个等宽文本框，上方标签标注「旧版本」「新版本」 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1024px
- 大屏（1440px+）：文件树 + 双栏编辑器 + 迷你地图
- 中屏（1024-1440px）：文件树可折叠，编辑器双栏自适应
- 移动端不作为主要目标
