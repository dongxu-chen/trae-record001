# 3D模型切割工具

一个基于 Web 的 3D 模型切割工具，支持通过平面拖拽进行切片切割，生成切割后的模型分块。

## 技术栈

- **前端**: React + Three.js + three-bvh-csg
- **后端**: Node.js + Express
- **构建工具**: Vite

## 功能特性

- 📁 **模型上传**: 支持 GLB、GLTF、OBJ、STL 格式的 3D 模型上传
- ✂️ **平面切割**: 通过拖拽切割平面进行模型切割
- 🔄 **多平面支持**: 支持添加多个切割平面，可分别调整方向和位置
- 👁️ **切割预览**: 实时预览切割效果，调整平面时即时更新
- 💾 **切块导出**: 支持将切割后的块单独导出为 GLB、GLTF、OBJ、STL 格式
- 🎯 **交互控制**: 支持平面拖拽、旋转、翻转等操作
- 🎨 **可视化**: 切割后的模型块使用不同颜色区分显示

## 使用说明

### 1. 上传模型

- 点击或拖拽 3D 模型文件到上传区域
- 支持的格式: GLB、GLTF、OBJ、STL
- 最大文件大小: 50MB

### 2. 添加切割平面

1. 选择平面方向（X轴、Y轴、Z轴、对角）
2. 点击「添加切割平面」按钮
3. 在 3D 视图中拖拽平面调整切割位置
4. 双击平面可翻转法线方向

### 3. 调整切割平面

- **拖拽移动**: 点击并拖拽平面调整切割位置
- **精确控制**: 在侧边栏选中平面后，使用旋转按钮调整角度
- **翻转方向**: 点击 🔄 按钮或双击平面翻转切割方向
- **重置平面**: 点击「重置平面」按钮恢复默认位置

### 4. 预览切割效果

- 勾选「实时预览切割」选项
- 调整平面时会实时显示切割后的预览效果
- 预览模式下切割块会有轻微偏移以便观察

### 5. 执行切割

1. 调整好所有切割平面的位置
2. 点击「执行切割」按钮
3. 切割完成后会自动显示切割结果
4. 勾选「显示切割结果」可以切换显示/隐藏切割块

### 6. 导出模型

- 选择导出格式（GLB、GLTF、OBJ、STL）
- 点击「全部导出」将所有切块分别导出
- 点击「合并导出」将所有切块合并为一个文件导出
- 点击每个切块旁边的 💾 按钮单独导出该切块

## 核心算法说明

### CSG 切割算法

使用 `three-bvh-csg` 库实现基于边界体积层次（BVH）的布尔运算：

1. **创建切割刷**: 根据平面参数创建一个足够大的立方体作为切割工具
2. **布尔减法**: 用原模型减去切割立方体，得到平面一侧的模型
3. **反向切割**: 翻转平面法线，再次执行减法得到另一侧的模型
4. **多平面切割**: 依次使用每个平面对所有切块进行递归切割

### 平面参数表示

切割平面使用标准平面方程 `ax + by + cz + d = 0` 表示：
- `(a, b, c)` 是平面法线向量
- `d` 是平面常数（决定平面距离原点的距离）

## 技术要点

- **性能优化**: 使用 three-mesh-bvh 加速光线检测和碰撞计算
- **内存管理**: 及时释放 Three.js 几何体和材质，避免内存泄漏
- **坐标变换**: 正确处理模型矩阵、世界坐标和局部坐标的转换
- **交互体验**: 拖拽时禁用轨道控制器，防止视角误操作

## 常见问题

**Q: 切割后模型出现破面？**
A: 这通常是因为模型存在非流形几何或共面问题。尝试使用更简单的模型，或在切割前检查模型拓扑。

**Q: 大模型切割很慢？**
A: 切割速度与模型面数成正比。对于面数超过 10 万的模型，建议先进行减面处理。

**Q: 导出的模型在其他软件中显示异常？**
A: 请确保导出格式与目标软件兼容。GLB 格式兼容性最好，推荐优先使用。
