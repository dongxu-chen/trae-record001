# React Flow 可视化表单编排设计器

基于 React + React Flow + Ant Design 构建的节点化表单编排工具

## 功能特性

### 1. 节点类型
- **控制流节点**
  - 开始节点：流程起点
  - 结束节点：流程终点
  - 分支节点：支持条件判断，true/false 两个分支
  - 循环节点：支持循环条件和最大循环次数

- **表单字段节点**
  - 输入框：单行文本输入
  - 文本域：多行文本输入
  - 下拉选择：下拉菜单选择
  - 单选框：单选按钮组
  - 多选框：复选框组
  - 日期选择：日期选择器
  - 时间选择：时间选择器
  - 开关：开关组件
  - 评分：星级评分
  - 滑块：滑动输入条

### 2. 画布操作
- 拖拽添加节点
- 节点拖拽移动
- 节点连线连接
- 点击节点选中并显示属性面板
- 画布缩放、平移
- 迷你地图导航
- 清空画布

### 3. 属性配置
- 基础属性：标签、字段名称
- 表单属性：占位符、是否必填、验证规则
- 数据流：输入/输出字段映射
- 分支节点：条件表达式、分支标签
- 循环节点：循环条件、最大循环次数

### 4. 导出/导入
- 导出 JSON 配置文件
- 导入 JSON 配置文件

### 5. 表单预览
- 实时预览表单效果
- 支持表单验证
- 提交数据展示

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 技术栈
- **React 18**: 前端框架
- **React Flow**: 节点编排核心库
- **Ant Design**: UI 组件库
- **Zustand**: 状态管理
- **Vite**: 构建工具

## 使用说明

### 1. 添加节点
- 从左侧节点库拖拽节点到画布

### 2. 连接节点
- 从节点的输出句柄拖拽到另一个节点的输入句柄

### 3. 配置节点
- 点击画布上的节点，右侧显示属性面板
- 在属性面板中配置节点属性

### 4. 预览表单
- 点击顶部工具栏的"预览表单"按钮
- 查看表单字段渲染效果

### 5. 导出/导入
- 点击"导出JSON"下载配置文件
- 点击"导入JSON"上传配置文件恢复画布
