# Clipboard Sync - 跨平台剪贴板同步工具

一个安全、高效的跨平台剪贴板同步工具，支持文本、图片、文件在多设备间实时同步，采用端到端加密保护您的隐私。

## ✨ 功能特性

- 🔄 **多类型支持** - 支持文本、图片、单文件、多文件同步
- 🔒 **端到端加密** - 采用 AES-256-GCM 算法，数据全程加密传输
- 🌐 **WebRTC 点对点** - 直接设备间传输，不经过中间服务器
- 🏠 **局域网优先** - 自动检测局域网设备，优先局域网直连，速度更快
- 📜 **历史记录管理** - 剪贴板历史可回溯、可搜索、可收藏
- ⌨️ **快速粘贴** - 自定义快捷键唤起历史记录选择器
- 💻 **跨平台** - 支持 Windows、macOS、Linux
- 📱 **设备管理** - 查看在线设备，支持单独发送到指定设备

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **桌面框架**: Electron
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **网络通信**: WebRTC (simple-peer) + WebSocket
- **加密算法**: AES-256-GCM (crypto-js)
- **数据存储**: electron-store
- **路由**: React Router

## 📦 安装与运行

### 前置要求

- Node.js >= 18
- npm 或 yarn

### 安装依赖

```bash
npm install
```

1. 先启动信令服务器（用于设备发现和 WebRTC 信令交换）：




## 🚀 使用说明

### 首次配置

1. 安装并启动应用后，打开「设置」页面
2. 设置设备名称（将显示在其他设备上）
3. 确保所有同步设备使用**相同的加密密钥**
4. 配置信令服务器地址（默认 `ws://localhost:33446`）
5. 在所有需要同步的设备上重复上述配置

### 同步剪贴板

1. 确保信令服务器正在运行
2. 在两台或多台设备上启动应用并连接到同一信令服务器
3. 复制任意内容（文本、图片或文件）
4. 内容将自动同步到其他已连接的设备
5. 收到新内容时会显示系统通知

### 使用快速粘贴

1. 按下预设的快捷键（默认 `Ctrl+Shift+V`）
2. 在弹出的窗口中搜索或浏览历史记录
3. 使用 `↑↓` 键选择，`Enter` 键确认粘贴
4. 内容将自动写入剪贴板

### 管理历史记录

- 点击任意历史记录卡片可快速复制
- 点击卡片右上角菜单可进行更多操作：
  - 复制到剪贴板
  - 添加/取消收藏
  - 发送到指定设备
  - 删除记录
- 使用顶部搜索框搜索历史记录
- 使用筛选按钮按类型筛选（全部/文本/图片/文件/收藏）

### 局域网优先模式

应用会自动检测设备是否在同一局域网：
- 局域网设备会显示「LAN」标签
- 发送数据时优先通过局域网传输
- 可在设置中开启「仅局域网模式」，拒绝非局域网连接

## 🔐 安全说明

### 加密机制

- 所有数据在发送前使用 AES-256-GCM 算法加密
- 加密密钥由用户自主管理和分发
- 服务器仅转发加密数据，无法解密内容
- 初始向量（IV）随机生成，确保相同内容加密结果不同

### 密钥管理

- 首次启动时自动生成随机密钥
- 可在设置中生成新密钥（会导致与现有设备断开）
- **重要**：请妥善保管密钥，丢失后无法解密历史数据
- 所有需要同步的设备必须使用完全相同的密钥

## 📡 信令服务器

信令服务器用于设备发现和 WebRTC 连接建立，不处理实际的剪贴板数据。

### 部署

```bash
node server/signaling-server.js
```

默认监听端口 `33446`，可通过环境变量 `PORT` 修改：

```bash
PORT=8080 node server/signaling-server.js
```

### API

- WebSocket 端点：`ws://host:port`
- HTTP 健康检查：`http://host:port`

## 🧪 测试说明

### 测试多设备同步

1. 在一台机器上启动信令服务器
2. 启动两个应用实例（可在同一机器或不同机器）
3. 确保两个实例使用相同的加密密钥
4. 在任一实例中复制内容，观察另一实例是否收到

### 测试局域网优先

1. 确保两台设备在同一局域网
2. 启动应用并连接
3. 设备旁应显示「LAN」标签
4. 传输大文件测试速度

## 📝 开发注意事项

1. **加密密钥一致性**：所有设备必须使用完全相同的密钥，包括大小写
2. **信令服务器**：确保所有设备能访问到信令服务器
3. **防火墙**：WebRTC 需要开放随机端口，可能需要配置防火墙
4. **大文件传输**：文件会自动分块传输，但过大文件（>100MB）可能较慢
5. **剪贴板监控**：应用会定期轮询剪贴板（默认 500ms），可能会消耗少量 CPU

## 🔧 常见问题

### Q: 设备无法发现对方？
A: 检查以下几点：
   - 信令服务器是否正常运行
   - 所有设备是否连接到同一信令服务器
   - 防火墙是否阻止了连接
   - 加密密钥是否完全一致

### Q: 同步速度慢？
A: 
   - 检查设备是否在同一局域网（应显示「LAN」标签）
   - 大文件传输需要时间，请耐心等待
   - 尝试关闭其他占用带宽的程序

### Q: 收到乱码或无法解密？
A: 
   - 确认所有设备使用完全相同的加密密钥
   - 检查密钥是否被意外修改
   - 历史数据使用旧密钥加密，更换密钥后无法解密

### Q: 快捷键不生效？
A: 
   - 检查快捷键是否与其他程序冲突
   - 在设置中尝试更换其他快捷键
   - Linux 下可能需要特殊权限
