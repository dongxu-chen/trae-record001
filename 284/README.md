# 促销活动效果评估模型

基于因果推断的促销活动效果评估系统，使用双重差分法(DID)和倾向性得分匹配(PSM)剥离自然增长，准确估计促销活动的真实销售提升率。

## 功能特性

- 🔬 **双重差分法 (DID)**: 利用时间序列数据，控制组与处理组对比，剥离时间趋势影响
- 🎯 **倾向性得分匹配 (PSM)**: 为每个促销商品匹配相似的未促销商品，消除选择偏差
- 📊 **交互式界面**: Streamlit 驱动的可视化分析平台
- 🔮 **效果预测模拟器**: 根据促销参数预测销售提升率
- 📈 **可视化分析**: 平行趋势检验、平衡性检验、处理效应可视化

## 使用方法

如果上传自定义CSV数据，需要包含以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| product_id | int | 商品ID |
| period | int | 时间周期（如第1周、第2周等） |
| category | str | 商品类别 |
| channel | str | 投放渠道 |
| base_sales | float | 基准销售额 |
| discount | float | 折扣力度（0-1，如0.2表示8折） |
| duration | int | 活动时长 |
| is_treated | bool | 是否参加促销 |
| is_treatment_period | bool | 是否处于促销期间 |
| treatment_period | int | 促销开始周期（未促销填-1） |
| sales | float | 当期销售额 |

### 因果推断方法说明

#### 双重差分法 (DID)

**适用场景**: 
- 有时间序列数据（促销前后都有观测值）
- 存在自然的控制组（未参与促销的商品）

**核心假设**: 平行趋势假设 - 如果没有促销活动，处理组和控制组的销售趋势应该相同。

**输出**: 
- 平均处理效应（销售提升率）
- 统计显著性（p值）
- 95%置信区间

#### 倾向性得分匹配 (PSM)

**适用场景**:
- 主要关注截面数据
- 需要控制组和处理组在特征上具有可比性

**核心假设**: 可忽略性假设 - 给定观测到的协变量，处理分配是"随机"的。

**输出**:
- 平均处理效应（ATT）
- 协变量平衡性检验
- 匹配质量评估

## 模型解读示例

```
双重差分法结果:
- 销售提升率: 18.5%
- p值: 0.0023
- 95%置信区间: [12.3%, 24.7%]

解读: 促销活动导致销售额提升18.5%，该效果在统计上显著（p<0.05），
我们有95%的信心认为真实提升率在12.3%到24.7%之间。
```

- **statsmodels**: 统计建模（DID）
- **scikit-learn**: 机器学习（PSM）
- **Pandas/Numpy**: 数据处理
- **Matplotlib/Seaborn**: 数据可视化

## 注意事项

1. **样本量要求**: 建议每个商品至少有3-5个周期的历史数据
2. **控制组选择**: 控制组商品应与处理组商品具有相似的特征
3. **平行趋势检验**: DID模型必须通过平行趋势检验结果才可信
4. **平衡性检验**: PSM匹配后需要协变量达到平衡（标准化差异<0.1）
