# 🏷️ 品牌忠诚度分析平台

一个基于 Python + 生存分析 + 聚类 + 归因模型 + Streamlit 的品牌忠诚度综合分析平台。

## 📋 功能特点

### 核心分析模块

1. **🔄 复购率分析**
   - 用户购买行为趋势分析
   - 购买频次和间隔分析
   - 复购概率预测
   - 消费金额分布

2. **👍 NPS 净推荐值分析**
   - NPS 得分计算与分布
   - 推荐者/被动者/贬损者分类
   - 子维度评分（易用性、产品质量、客户服务）
   - 各忠诚度层级 NPS 对比

3. **⚠️ 投诉率分析**
   - 投诉类型分布
   - 投诉严重程度分析
   - 投诉解决率和解决时间
   - 各层级投诉对比

4. **🧮 品牌忠诚度指数**
   - 五大维度加权评分：复购能力(30%)、推荐意愿(25%)、投诉处理(15%)、互动参与(15%)、价值贡献(15%)
   - 忠诚度分层（高/中/低）
   - 高价值用户识别
   - 风险用户预警

5. **👥 用户忠诚度分层**
   - K-Means / GMM 聚类算法
   - PCA 可视化聚类结果
   - 各层级用户特征画像
   - 最优聚类数评估（肘部法则、轮廓系数等）

6. **📉 生存分析**
   - Kaplan-Meier 生存曲线
   - 用户留存率分析
   - Cox 比例风险模型
   - 流失风险因素识别
   - 分群体/分渠道对比

7. **🔍 影响因素归因**
   - 集成特征重要性（RF + GBDT + LR）
   - SHAP 值分析
   - 流失驱动因素识别
   - 分群体归因分析
   - 相关性热力图

8. **💡 提升策略推荐**
   - 分层策略（高/中/低忠诚度用户）
   - 归因驱动的改进建议
   - 分维度提升方案
   - 行动计划优先级矩阵
   - 预期收益估算

## 🛠️ 技术栈

- **Python 3.8+**
- **Streamlit** - 交互式 Web 界面
- **Pandas / NumPy** - 数据处理
- **Scikit-learn** - 聚类、归因模型
- **Lifelines** - 生存分析
- **SHAP** - 可解释性分析
- **Plotly** - 数据可视化

## 📊 分析流程

1. **数据生成**：模拟 1000+ 用户的 3 年行为数据
   - 用户档案（年龄、性别、细分群体、渠道、区域）
   - 购买历史（时间、金额、品类、退货、折扣）
   - NPS 调研（评分、子维度评价）
   - 投诉记录（类型、严重程度、解决情况）
   - 互动行为（邮件、点击、社交媒体、客服、APP访问）

2. **生存分析**：
   - 构建用户生存时间和流失状态
   - Kaplan-Meier 估计留存曲线
   - Cox PH 模型识别风险因素
   - 复购概率预测

3. **聚类分析**：
   - 构建 20+ 维用户特征
   - K-Means 聚类分为 3 个层级
   - 根据综合得分标记高/中/低忠诚度
   - PCA 降维可视化

4. **归因分析**：
   - 集成模型计算特征重要性
   - SHAP 值解释每个特征的贡献
   - 识别正负向驱动因素
   - 流失关键因素分析

5. **忠诚度指数**：
   - 五大维度标准化评分
   - 加权计算综合指数（0-100分）
   - 自动分层（≥70高，40-70中，<40低）
   - 生成针对性提升策略

## 📈 输出结果

运行分析后将生成以下结果文件（保存在 `results/` 目录）：

- `customer_loyalty_scores.csv` - 所有用户的忠诚度评分
- `cluster_profiles.csv` - 各忠诚度层级用户画像
- `feature_importance.csv` - 特征重要性排名
- `factor_impact.csv` - 各因素对忠诚度的影响
- `recommendations.csv` - 策略建议
- `survival_metrics.csv` - 生存分析指标

## 🎯 核心指标

| 指标 | 说明 |
|------|------|
| **品牌忠诚度指数** | 0-100分，综合评估用户忠诚度 |
| **NPS 净推荐值** | 推荐者% - 贬损者% |
| **复购率** | 购买两次及以上用户占比 |
| **投诉率** | 有投诉记录用户占比 |
| **用户流失率** | 超过90天未购买用户占比 |
| **中位生存期** | 50%用户留存的天数 |

## 💡 策略建议示例

### 高忠诚度用户（维持与增值）
- 推出专属会员计划和 VIP 礼遇
- 建立品牌大使计划，鼓励口碑传播
- 预计提升客户终身价值 15-25%

### 中忠诚度用户（提升与转化）
- 分析购买模式，推送个性化推荐
- 提供忠诚度积分和奖励计划
- 预计 20-30% 用户可升级至高忠诚度

### 低忠诚度用户（挽回与激活）
- 开展赢回活动，提供特别优惠
- 深入分析流失原因，针对性改进
- 预计可挽回 15-20% 的低忠诚度用户
