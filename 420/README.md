# 实时视频风格迁移系统

基于 PyTorch + OpenCV + PyQt 的实时视频风格迁移应用，支持多种艺术风格实时转换。

## 功能特性

- 🎨 **多种艺术风格**: 支持梵高、莫奈、毕加索等多种预训练风格模型
- 🎭 **多风格混合**: 实时加权混合多个风格，创造独特效果
- 🖼️ **实例分割引导**: 前景背景应用不同风格，实现创意合成
- 🤖 **自动强度调节**: 根据内容复杂度智能调整风格强度
- ⚡ **实时处理**: 基于快速风格迁移网络，实现低延迟视频风格转换
- 🖥️ **GPU加速**: 支持 CUDA GPU 加速，可选 TensorRT 进一步优化
- 📱 **多分辨率**: 支持多种采集和处理分辨率配置
- 🎚️ **风格强度调节**: 可实时调整风格化强度
- 📊 **帧率稳定**: 帧缓存队列 + 动态帧率调整，确保流畅播放
- 🧩 **分块风格化**: 高分辨率图像分块处理，重叠拼贴降低显存占用
- 🚀 **TensorRT离线预构建**: 引擎离线构建，启动直接加载
- 💾 **帧保存**: 一键保存当前风格化帧

## 安装依赖

```bash
pip install -r requirements.txt
```

### 可选依赖

- **TensorRT**: 用于进一步加速推理（需要 NVIDIA GPU 和 CUDA）
- **CUDA Toolkit**: 版本需与 PyTorch 兼容

## 下载预训练模型

将预训练的风格迁移模型文件（`.pth` 格式）放入 `models/` 目录。

### 模型下载来源

可以从以下开源项目下载预训练模型：

1. **Johnson 快速风格迁移模型**:
   - GitHub: https://github.com/pytorch/examples/tree/master/fast_neural_style
   - 包含: 梵高《星夜》、毕加索、马赛克、糖果风格等

2. **官方 PyTorch 模型**:
   ```bash
   # 下载示例模型
   python -c "
   import torch.hub
   model = torch.hub.load('pytorch/examples', 'fast_neural_style', 
                          style='starry_night', source='github')
   torch.save(model.state_dict(), 'models/starry_night.pth')
   "
   ```

### 可用风格命名建议

建议将模型文件命名为以下格式以便识别：
- `starry_night.pth` - 梵高《星夜》
- `mosaic.pth` - 马赛克风格
- `candy.pth` - 糖果风格
- `the_scream.pth` - 《呐喊》风格
- `udnie.pth` - Udnie 风格
- `picasso.pth` - 毕加索风格
- `monet.pth` - 莫奈风格

## 使用方法

### 启动应用

```bash
python main.py
```

### 操作说明

1. **摄像头设置**:
   - 选择可用摄像头
   - 设置采集分辨率（自动/360p/480p/720p/1080p）
   - 设置目标帧率（15-60 FPS）
   - 点击"开始"启动摄像头

2. **风格设置**:
   - 从下拉菜单选择艺术风格
   - 拖动滑块调整风格强度（0%-100%）
   - 选择处理分辨率（影响性能）
   - 勾选"显示原始画面"可对比效果

3. **加速设置**:
   - 启用 GPU 加速（需 CUDA 支持）
   - 启用 TensorRT 加速（需 TensorRT 安装）
   - 点击"应用加速设置"生效

4. **保存图像**:
   - 点击"保存当前帧"将当前画面保存为图片

## 性能优化建议

| 设备 | 推荐处理分辨率 | 预期 FPS |
|------|---------------|----------|
| CPU (i7) | 360p | 5-10 |
| GPU (GTX 1060) | 480p | 20-30 |
| GPU (RTX 2060+) | 720p | 30-60 |

1. 降低处理分辨率可显著提升帧率

3. 关闭其他 GPU 密集型应用
4. 使用最新的 NVIDIA 驱动程序

## 多风格混合

支持同时加载多个风格模型并进行加权混合：

### 使用方法

1. 切换到"多风格混合"标签页
2. 从列表中选择多个风格（按住Ctrl多选）
3. 调整风格权重滑块（0.10-1.00）
4. 点击"应用多风格"按钮

### 混合原理

```
输出 = (风格A × 权重A + 风格B × 权重B + ...) / (权重A + 权重B + ...)
```

示例：梵高(0.6) + 莫奈(0.4) = 60%梵高 + 40%莫奈的混合效果

## 实例分割引导

将前景和背景分别应用不同风格：

### 分割方法

| 方法 | 适用场景 | 说明 |
|------|---------|------|
| 背景差 | 静态背景 | 基于 MOG2 背景减除 |
| 肤色 | 人像视频 | 基于 HSV 肤色检测 |
| 边缘 | 物体轮廓 | 基于 Canny 边缘检测 |

### 使用方法

1. 勾选"启用分割"
2. 选择分割方法
3. 前景使用主风格，背景选择"背景风格"
4. 可选：勾选"显示分割遮罩"查看分割效果

## 自动强度调节

根据视频内容复杂度自动调整风格强度：

### 复杂度评估指标

- **边缘密度**: Canny 边缘检测计算
- **纹理方差**: Laplacian 方差
- **信息熵**: 灰度直方图熵
- **色彩多样性**: HSV 色相标准差

### 强度映射规则

| 复杂度 | 风格强度 | 说明 |
|--------|---------|------|
| < 0.2 | 100% | 简单场景，满强度 |
| 0.2-0.5 | 80-100% | 渐变过渡 |
| 0.5-0.7 | 80% | 中等复杂度 |
| > 0.7 | 40-80% | 复杂场景，降低强度避免过度风格化 |

## 技术架构

- **风格迁移网络**: Johnson 等人提出的快速风格迁移网络（TransformerNet）
- **推理框架**: PyTorch，可选 TensorRT 优化
- **视频捕获**: OpenCV VideoCapture
- **图形界面**: PyQt5
- **多线程处理**: QThread 实现视频捕获与 UI 分离

## 常见问题

**Q: 摄像头无法启动？**
A: 检查摄像头是否被其他程序占用，尝试更换摄像头索引。

**Q: 模型加载失败？**
A: 确保模型文件格式正确（.pth），且与网络结构兼容。

**Q: 帧率太低？**
A: 降低处理分辨率，启用 GPU/TensorRT 加速，关闭其他应用。

**Q: TensorRT 不工作？**
A: 确保安装了正确版本的 TensorRT 和 CUDA，且 PyTorch 支持 CUDA。
