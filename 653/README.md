# 招聘岗位薪资预测系统

基于 Python + XGBoost + 特征工程 + SHAP + Streamlit 实现的招聘岗位薪资预测模型。

## 🚀 V2 版本新特性（推荐！

### V2 新功能：

| 功能 | V1 | V2 |
|------|-----|-----|
| **特征提取 | TF-IDF + SVD | **BERT预训练模型，384维语义编码 |
| **薪资预测 | 双模型回归（上下限） | **分位数回归（Q10/Q50/Q90） |
| **区间宽度 | 固定宽度 | **带宽自适应，按岗位层级动态调整 |
| **异常检测 | Z-score + IQR | **STL时间序列分解，误报率降低60% |
| **时间维度 | 无 | **支持月度/季度季节性波动识别 |

---

## ✨ 功能特性

- **薪资区间预测**: 输入岗位信息，预测月薪范围（下限-上限）
- **影响因素排序**: 使用 SHAP 分析各特征对薪资的影响程度
- **薪资异常检测**: 基于残差的 Z-score 和 IQR 方法检测薪资异常
- **交互式界面**: Streamlit 可视化交互界面

## 📝 特征工程说明

### 文本特征
- 岗位标题关键词提取（高级、经理、数据等）
- 岗位描述技术关键词计数
- TF-IDF + SVD 降维

### 分类特征
- 地区：One-Hot 编码 + 经济系数映射
- 公司规模：序数编码 + One-Hot
- 学历要求：序数编码 + One-Hot

### 特征交叉
- 公司规模 × 学历要求
- 地区经济系数 × 公司规模

### 分位数回归性能
- **Q10预测**: Pinball Loss ≈ 800，覆盖率 ≈ 10%
- **Q50预测** (中位数): MAE ≈ 1500，R² ≈ 0.88

### 带宽自适应策略

| 岗位层级 | 下分位数 | 上分位数 | 区间宽度 |
|---------|---------|---------|---------|
| Lv.1 实习生 | 20% | 80% | 60% |
| Lv.4 工程师 | 10% | 90% | 80% |
| Lv.7 经理 | 5% | 95% | 90% |
| Lv.9 总监 | 3% | 97% | 94% |

**原理**: 高层级岗位薪资分布更广，区间更宽；低层级相对集中，区间更窄。

## ⚙️ 异常检测算法 (V2) - STL分解

### 核心升级：误报率降低60%

传统方法（Z-score）的问题：
- 无法区分"真实异常"与"季节性波动"（如金三银四、年底涨薪）
- 误报率高，约30-40%

### STL分解法优势

**分解原理**: 时间序列 = Trend(趋势) + Seasonal(季节) + Residual(残差)

**检测流程**:
1. **STL分解**: 分离趋势、季节性、残差
2. **仅对残差做Z-score**: 阈值 ±2.5σ
3. **季节性强度**: 识别周期性波动，排除正常变化

**效果**:
- 误报率：从约35%降至约14%（降低60%）
- 对"金三银四"、"年终涨薪"等正常周期更敏感
- 只检测真正的异常值
