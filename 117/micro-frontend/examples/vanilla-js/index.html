🟨 原生JavaScript嵌入示例

展示如何在纯HTML/JS项目中使用仪表盘Web Components

💡 提示：Web Components是原生浏览器特性，兼容任何前端框架或无框架环境！

📦 方式一：通过Script标签引入

<!-- 1. 引入SDK -->
<script type="module" src="/dist/dashboard-sdk.esm.js"></script>

<!-- 2. 直接使用自定义标签 -->
<line-chart title="销售趋势" height="300px" smooth></line-chart>
<bar-chart title="月度对比" height="300px"></bar-chart>
<pie-chart title="流量来源" doughnut></pie-chart>

🔧 方式二：通过SDK动态创建

<script type="module">
import { createDashboardSDK } from './dist/dashboard-sdk.esm.js';

// 初始化SDK
const sdk = createDashboardSDK();

// 动态创建图表
const chart = sdk.createLineChart('#chart-container', {
  title: '实时数据',
  theme: 'dark',
  smooth: true
});

// 监听事件
sdk.on('chart-click', (payload) => {
  console.log('图表被点击:', payload);
});

// 所有图表实例
console.log(sdk.getAllCharts());
</script>

📡 跨组件通信示例

// 组件A发送消息
sdk.send('target-chart-id', 'update-data', {
  series: [{ name: '新数据', data: [1, 2, 3] }]
});

// 广播消息给所有组件
sdk.broadcast('update-theme', { theme: 'dark' });

// 订阅消息
sdk.on('refresh-chart', (payload) => {
  console.log('收到刷新指令');
});
