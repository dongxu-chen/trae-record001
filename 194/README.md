# 交通拥堵指数预测模型

基于LightGBM + 图神经网络(GNN)的交通拥堵指数预测系统，支持未来15/30/60分钟的路段拥堵指数预测。

## 功能特性

- **多源数据融合**：整合历史路况数据（速度、流量、占有率）、时间特征、天气信息、事件信息
- **双模型架构**：
  - LightGBM：处理结构化特征，捕捉非线性关系
  - 图神经网络(GNN)：利用路网拓扑结构，捕捉路段间的空间相关性
- **有向路网图**：支持单向/双向道路、交通流向标识、道路容量属性
- **Sigmoid输出压缩**：预测输出使用Sigmoid压缩到0-10区间
- **多时间跨度预测**：支持15分钟、30分钟、60分钟预测
- **栅格瓦片热力图**：支持瓦片金字塔、按需加载、分级渲染，优化大数据量性能
- **事件影响模拟**：输入临时封路或事故信息，预测影响范围和持续时间
- **路径规划集成**：基于预测拥堵推荐最优路线，支持多时间跨度对比
- **路况趋势播报**：生成整点播报、路段详情、语音播报文案和APP推送通知
- **可视化输出**：拥堵热力图、路网可视化、预测对比图

## 安装依赖

```bash
pip install -r requirements.txt
```

注意：PyTorch和DGL需要根据CUDA版本选择对应的安装包。

## 使用方法

### 1. 训练模型并预测

```bash
python main.py --mode both
```

### 2. 仅训练模型

```bash
python main.py --mode train
```

### 3. 仅预测（需要已训练好的模型）

```bash
python main.py --mode predict
```

### 4. 重新生成数据

```bash
python main.py --mode both --generate_data
```

## 输入特征

| 类别 | 特征 |
|------|------|
| 路况 | speed(速度), flow(流量), occupancy(占有率) |
| 时间 | hour, minute, weekday, is_weekend, morning_peak, evening_peak |
| 天气 | temperature(温度), rainfall(降雨量), visibility(能见度), weather_type |
| 事件 | has_event, event_type, event_severity |

## 输出说明

- **预测结果**：各路段在15/30/60分钟后的拥堵指数（1-5，越高越拥堵）
- **可视化图表**：
  - 拥堵热力图（heatmap_*.png）
  - 路网拥堵图（network_*.png）
  - 预测对比图（comparison_*.png）
  - 多时间跨度对比（horizon_comparison_*.png）
  - 模型对比图（model_comparison_*.png）

## 拥堵指数说明（0-10）

| 指数 | 等级 | 说明 |
|------|------|------|
| 0-2 | 非常顺畅 | 道路完全畅通 |
| 2-4 | 轻微 | 基本畅通 |
| 4-6 | 中度 | 行驶缓慢 |
| 6-8 | 严重 | 交通拥堵 |
| 8-10 | 极度严重 | 完全堵塞 |

## 栅格瓦片系统说明

热力图采用瓦片金字塔技术优化性能：
- **多分辨率层级**：支持5级分辨率金字塔
- **按需加载**：TileCache缓存机制，LRU淘汰策略
- **分级渲染**：根据缩放级别自动选择合适分辨率
- **独立存储**：每个瓦片独立保存，便于分布式部署

## 事件影响模拟

支持多种交通事件的影响范围预测：
- **事件类型**：事故(accident)、封路(road_closure)、施工(construction)、活动(special_event)、天气(weather)
- **影响传播**：基于路网拓扑的距离衰减模型
- **输出内容**：影响路段数、峰值时间、预计恢复时间、绕行建议

## 路径规划

基于预测拥堵的智能路线推荐：
- **多目标优化**：综合考虑距离和拥堵程度
- **多时间跨度**：支持15/30/60分钟预测的路线规划
- **封路绕行**：支持临时封路情况下的备选路线
- **输出内容**：推荐路线、预计行驶时间、拥堵等级评估

## 路况播报

生成多种格式的路况信息：
- **整点播报**：整体路况、拥堵热点、推荐路段、趋势预测
- **路段详情**：单个路段的多时间跨度预测和趋势分析
- **语音播报**：适合语音合成的口语化播报文本
- **APP推送**：高优先级告警、路线提醒、路况概况通知
