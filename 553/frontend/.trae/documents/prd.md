# Elasticsearch 分片均衡工具 - 产品需求文档

## 1. 产品概述

### 1.1 产品定位
Elasticsearch 索引分片均衡工具是一个运维监控与管理平台，帮助用户可视化监控 ES 集群分片分布状态，自动执行分片均衡迁移，支持冷热分离架构、磁盘水位感知和迁移限速控制。

### 1.2 目标用户
- Elasticsearch 集群运维工程师
- 数据平台管理员
- DevOps 团队

### 1.3 核心价值
- **可视化监控**：直观展示集群分片分布和磁盘使用情况
- **自动化均衡**：智能算法自动生成分片迁移计划
- **安全可控**：支持磁盘水位保护和迁移限速，避免影响业务
- **冷热分离**：支持基于节点属性的冷热数据分层管理

## 2. 功能需求

### 2.1 集群总览仪表盘
- 集群健康状态展示（绿色/黄色/红色）
- 节点数量、分片总数统计
- 实时迁移任务数
- 集群不均衡度指标

### 2.2 节点分片分布
- 节点列表卡片展示
- 每个节点的分片数量柱状图
- 磁盘使用率环形进度条
- 节点类型标识（热节点/冷节点）

### 2.3 分片可视化
- 索引分片矩阵视图
- 分片状态图例（主分片/副本分片/迁移中）
- 按索引筛选功能
- 节点分片详细列表

### 2.4 迁移管理
- 自动生成迁移计划
- 迁移计划预览和确认
- 手动迁移分片功能
- 迁移任务进度追踪

### 2.5 配置管理
- 磁盘水位阈值设置（低/高/洪水）
- 迁移速度限制设置
- 冷热分离开关和属性配置
- 自动均衡调度配置

### 2.6 实时监控
- 自动刷新数据
- WebSocket 实时推送（可选）
- 历史操作记录

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 < 2秒
- API 响应时间 < 500ms
- 支持 100+ 节点的大规模集群

### 3.2 兼容性
- 支持 Elasticsearch 7.x / 8.x
- 支持现代浏览器（Chrome 90+, Firefox 88+, Safari 14+）

### 3.3 安全性
- API 接口认证（Bearer Token）
- CORS 跨域配置
- 敏感操作二次确认

## 4. UI/UX 设计要求

### 4.1 视觉风格
- **主题**：深色科技风，运维控制台风格
- **主色调**：深蓝色 #1e3a5f，科技感
- **强调色**：
  - 成功/健康：绿色 #10b981
  - 警告/黄色状态：黄色 #f59e0b
  - 危险/红色状态：红色 #ef4444
  - 操作按钮：蓝色 #3b82f6
- **字体**：等宽字体用于数据展示，现代无衬线字体用于界面

### 4.2 交互设计
- 仪表盘数据卡片悬停动效
- 进度条平滑过渡动画
- 配置修改即时反馈
- 操作确认弹窗

### 4.3 响应式设计
- 桌面端优先设计
- 支持平板设备适配
- 关键信息在小屏设备可访问

## 5. 技术栈
- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS
- **状态管理**：React Query + Context
- **图表库**：Recharts
- **UI 组件**：Headless UI + Heroicons
