# 📊 用户行为路径分析工具

一个功能完整的用户行为路径分析工具，支持常见路径挖掘、转化漏斗分析、流失节点识别、桑基图可视化、路径对比和用户分群分析。

## ✨ 功能特性

### 核心功能
- **路径分析**：挖掘用户常见行为路径，支持按路径长度、频率筛选
- **桑基图可视化**：直观展示用户行为流转路径
- **转化漏斗**：自定义漏斗步骤，分析各环节转化率和流失率
- **流失分析**：识别用户流失节点，计算流失率
- **路径对比**：支持用户分组对比、时间段对比
- **用户分群**：按用户分组进行差异化分析
- **双模式运行**：支持ClickHouse数据库模式和本地示例数据模式

### ✨ 新增增强功能（v2.0）
1. **可折叠分组桑基图**
   - 事件按类别分组显示（page_view、engagement、cart、checkout、purchase、account）
   - 支持低频路径自动聚合，阈值可配置
   - 分组统计和聚合信息展示

2. **多群组并排对比**
   - 最多支持4个用户分组同时对比
   - 三种对比模式：路径对比、桑基图对比、漏斗对比
   - 可配置布局列数（1/2/3/4列并排展示）

3. **动态分群分析**
   - 支持用户自定义分群条件和维度
   - 12种可用维度：用户分组、设备类型、操作系统、浏览器、会话数、事件数等
   - 12种运算符：等于、不等于、包含、大于、小于、在列表中等
   - 支持AND/OR多条件组合逻辑

### ✨ 新增高级分析功能（v3.0）
4. **路径预测（马尔可夫链）**
   - 基于马尔可夫链模型预测用户下一步行为
   - 支持1/2/3阶马尔可夫链
   - 多步路径预测，展示完整行为演化路径
   - 各状态可预测性分析（信息熵指标）
   - 预测置信度评估

5. **异常路径检测**
   - 8种异常模式自动识别：跳步、回退、循环、罕见转移、死胡同、异常起点、快速退出、停滞
   - 支持自定义预期流程，检测跳步和回退
   - 异常严重级别分类（高/中/低）
   - 异常类型和严重级别分布可视化
   - 批量路径异常检测

6. **归因分析**
   - 6种归因模型对比：首次触达、末次触达、线性归因、时间衰减、位置归因、马尔可夫链
   - 多模型归因权重对比图表
   - 各事件转化提升度（Lift值）分析
   - 转化贡献路径统计
   - 可选择任意事件作为转化目标

## 🛠️ 技术栈

- **后端**：Python + ClickHouse
- **前端**：Streamlit + ECharts (pyecharts)
- **可视化**：桑基图、漏斗图、柱状图、饼图、热力图

## 🚀 快速开始

### 方式一：使用本地示例数据（推荐，无需ClickHouse）

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行应用：
```bash
streamlit run app.py
```

3. 在侧边栏勾选"使用本地示例数据"，点击"生成示例数据"即可开始体验！

### 方式二：使用ClickHouse数据库

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 配置环境变量：
```bash
cp .env.example .env
# 编辑.env文件，配置ClickHouse连接信息
```

3. 确保ClickHouse服务已启动

4. 运行应用：
```bash
streamlit run app.py
```

5. 在"数据库初始化"页面创建数据库表并导入示例数据

## 📊 数据模型

### 用户事件表 (user_events)

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | String | 用户ID |
| session_id | String | 会话ID |
| event_name | String | 事件名称 |
| event_time | DateTime | 事件时间 |
| page_url | String | 页面URL |
| referrer | String | 来源页面 |
| device_type | String | 设备类型 |
| os | String | 操作系统 |
| browser | String | 浏览器 |
| user_group | String | 用户分组 |
| event_properties | Map | 事件属性 |

## 🔧 配置说明

编辑 `config.py` 可以调整：
- `SESSION_TIMEOUT`：会话超时时间（秒）
- `MAX_PATH_LENGTH`：最大路径长度
- `MIN_PATH_FREQUENCY`：最小路径频率

## 📈 示例场景

### 基础场景
1. **电商转化分析**：分析从浏览商品到下单的转化漏斗
2. **用户留存分析**：按周/月查看用户留存热力图
3. **A/B测试对比**：对比两个版本的用户行为路径差异
4. **流失预警**：识别高流失率的节点，优化产品体验

### 增强功能应用场景
5. **路径简化分析**：使用桑基图分组功能，将100+个事件聚合为6个类别，清晰展示用户行为流向
6. **多版本并行测试**：同时对比4个用户分群的路径差异，快速识别最优版本
7. **高价值用户挖掘**：使用动态分群功能，筛选出"会话数>=5 AND 已购买=TRUE"的高价值用户，分析其行为特征
8. **流失用户定位**：创建"最近访问>14天 AND 会话数<2"的分群规则，精准识别流失风险用户
9. **设备差异化分析**：对比移动设备用户和桌面用户的行为路径差异，优化各端体验

### 高级分析应用场景
10. **实时行为引导**：使用路径预测功能，在用户当前节点推荐最可能的下一步行为，引导用户完成转化
11. **流程合规检测**：定义预期流程后，自动检测跳步（如直接从首页到支付）、回退等异常行为
12. **异常用户识别**：检测循环（重复浏览）、罕见转移（异常跳转）等异常模式，识别机器人或异常用户
13. **渠道归因优化**：使用6种归因模型对比分析，精准量化各触点对转化的贡献权重
14. **关键事件评估**：通过Lift值分析，发现哪些事件出现时转化率显著提升，优化产品引导策略
15. **马尔可夫链归因**：使用移除效应法，量化每个事件对整体转化率的实际贡献
