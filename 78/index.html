欢迎使用 GitHub Issues 博客评论系统

发布于 2026年5月13日 · 阅读约 2 分钟

这是一个基于 GitHub Issues + Utterances 的无后端博客评论系统示例。


功能特点

  • 纯前端实现，无需后端服务器
  • 使用 GitHub Issues 存储评论数据
  • 集成 Utterances 组件，支持 GitHub 登录评论
  • 通过 GitHub API 直接读取评论
  • 优雅的 GitHub 风格界面

如何使用

  1. 在 config.js 中配置你的 GitHub 仓库信息
  2. 确保仓库已安装 Utterances 应用
  3. 打开 index.html 即可看到效果
