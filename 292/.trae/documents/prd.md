## 1. 产品概述

低代码表单构建器是一个可视化的表单设计工具，用户可以通过拖拽组件快速构建复杂表单，支持数据校验、公式计算、条件显隐和多页签等高级功能。

- 主要目标：降低表单开发门槛，通过拖拽式操作快速生成专业级表单
- 目标用户：前端开发者、产品经理、业务人员
- 核心价值：生成标准化的JSON Schema，支持运行时渲染和数据提交

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 设计用户 | 无需注册 | 拖拽设计表单、配置组件属性、预览表单、导出Schema |

### 2.2 功能模块

1. **表单设计器**：组件面板、画布区域、属性配置面板
2. **组件库**：基础组件、高级组件、布局组件
3. **属性配置**：通用属性、数据校验、公式计算、条件显隐
4. **多页签管理**：页签创建、删除、排序、切换
5. **Schema管理**：实时预览JSON Schema、导出Schema
6. **表单预览**：运行时渲染、表单提交、数据收集

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 表单设计器 | 组件面板 | 展示可拖拽的表单组件列表，支持分类筛选 |
| 表单设计器 | 设计画布 | 拖拽放置组件、组件排序、组件删除 |
| 表单设计器 | 属性面板 | 配置选中组件的属性、校验规则、公式、条件 |
| 表单设计器 | 页签栏 | 多页签管理，创建/删除/切换页签 |
| 表单设计器 | 工具栏 | 撤销/重做、清空、预览、导出Schema |
| 表单预览 | 运行时渲染 | 根据Schema渲染完整表单，支持交互 |
| 表单预览 | 数据提交 | 表单验证、数据收集、结果展示 |
| Schema预览 | JSON展示 | 实时显示表单结构的JSON Schema |

## 3. 核心流程

用户进入设计器 → 从组件面板拖拽组件到画布 → 选中组件配置属性 → 配置校验规则和公式 → 设置条件显隐 → 添加多页签 → 预览表单效果 → 导出JSON Schema

```mermaid
flowchart LR
    A["进入设计器"] --> B["拖拽组件"]
    B --> C["配置属性"]
    C --> D["配置校验/公式"]
    D --> E["设置条件显隐"]
    E --> F["添加页签(可选)"]
    F --> G["预览表单"]
    G --> H["导出JSON Schema"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝紫色系（#6366F1），体现专业和科技感
- 辅助色：青色（#06B6D4）用于交互元素，橙色（#F59E0B）用于警告提示
- 中性色：深灰（#1E293B）背景，浅灰（#F8FAFC）画布区域
- 按钮风格：圆角8px，悬停时有微妙的阴影和色彩变化
- 字体：使用Geist Sans作为主要字体，现代简洁
- 布局：三栏式布局（左：组件面板，中：设计画布，右：属性配置）
- 图标：使用Lucide图标库，统一线性风格

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 表单设计器 | 组件面板 | 分类标签、组件卡片、拖拽手柄、悬停效果 |
| 表单设计器 | 设计画布 | 网格背景、拖放区域、组件选中状态、拖拽占位符 |
| 表单设计器 | 属性面板 | 分组折叠面板、表单控件、开关按钮、颜色选择器 |
| 表单设计器 | 工具栏 | 图标按钮、分割线、操作提示 |
| 表单预览 | 表单区域 | 卡片式容器、字段间距、验证提示、提交按钮 |
| Schema预览 | 代码区域 | 语法高亮、行号、复制按钮、折叠代码块 |

### 4.3 响应式

- 桌面端优先：三栏完整布局
- 平板端：左右面板可折叠收起
- 移动端：采用Tab切换方式，画布全屏显示
- 触摸优化：增大拖拽区域和点击目标

### 4.4 交互细节

- 拖拽时的半透明预览效果
- 组件选中时的高亮边框和控制点
- 属性配置实时生效到画布
- 平滑的页签切换动画
- 表单验证的即时反馈提示
