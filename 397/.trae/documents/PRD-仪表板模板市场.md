## 1. 产品概述
仪表板模板市场是一个面向企业和开发者的可视化仪表板模板共享平台，提供运营、销售、财务、运维等多行业专业模板，支持一键应用、自定义编辑、社区互动等功能。
- 解决企业快速搭建数据可视化仪表板的需求，降低开发成本
- 构建模板创作者社区，促进优质可视化资源的共享与传播

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱/手机号注册 | 浏览模板、下载应用、评分评论、收藏模板 |
| 创作者 | 邮箱/手机号注册 | 上传模板、管理自己的模板、查看下载统计 |
| 管理员 | 后台登录 | 审核模板、管理用户、配置分类 |

### 2.2 功能模块
1. **首页**：模板分类导航、热门推荐、最新上架、搜索栏
2. **模板列表页**：多维度筛选、排序、卡片展示
3. **模板详情页**：模板预览、评分评论、下载统计、相关推荐
4. **模板编辑器**：拖拽式布局、组件配置、数据绑定、实时预览
5. **个人中心**：我的收藏、我的下载、我的模板、账号设置
6. **模板上传页**：模板信息填写、文件上传、预览配置

## 3. 核心流程
用户浏览模板市场 → 选择感兴趣的模板 → 查看详情与预览 → 一键下载/应用 → 进入编辑器自定义修改 → 导出或保存到个人空间 → 对模板进行评分评论

```mermaid

    A["用户访问首页"] --> B["浏览/搜索模板"]
    B --> C["查看模板详情"]
    C --> D["下载/应用模板"]
    D --> E["进入编辑器"]
    E --> F["拖拽调整布局"]
    F --> G["配置组件属性"]
    G --> H["绑定数据源"]
    H --> I["预览效果"]
    I --> J["导出/保存"]
    J --> K["返回详情页评分评论"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深靛蓝 #1E3A8A，搭配活力橙 #F97316 作为强调色
- **背景**：深色主题 #0F172A，营造专业数据可视化氛围
- **按钮风格**：圆角 8px，悬浮微动效，渐变色按钮
- **字体**：标题使用 Inter SemiBold，正文使用 Inter Regular，等宽字体用于数据展示
- **布局**：卡片式布局，毛玻璃效果，层次分明的阴影系统
- **图标**：使用 Ant Design 图标库，统一线性风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|---------|----------|---------|
| 首页 | Hero 区域 | 渐变背景、大标题、搜索框、分类快捷入口 |
| 首页 | 模板网格 | 响应式卡片网格，悬停缩放效果 |
| 模板列表页 | 筛选侧边栏 | 折叠式筛选器，多选标签 |
| 模板详情页 | 预览画廊 | 大图轮播，缩略图导航 |
| 模板编辑器 | 三栏布局 | 左组件库、中画布、右属性面板 |
| 个人中心 | 数据概览 | 统计卡片、趋势图表 |

### 4.3 响应式
- 桌面端（1440px+）：四列网格布局，侧边栏展开
- 平板端（768px-1439px）：两列网格布局，侧边栏可折叠
- 移动端（<768px）：单列布局，底部导航，简化编辑功能

### 4.4 动效设计
- 页面加载：元素渐入动画，延迟错落效果
- 卡片悬停：上浮 4px，阴影加深，边框高亮
- 编辑器拖拽：组件半透明跟随，放置位置虚线提示
- 数据更新：数字滚动动画，图表平滑过渡
