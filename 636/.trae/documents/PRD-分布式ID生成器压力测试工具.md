## 1. 产品概述

分布式ID生成器压力测试工具，用于模拟高并发场景下测试ID生成服务的性能指标（QPS、延迟）和正确性（唯一性）。支持多种主流ID算法，提供可视化测试报告。

- **核心用途**：评估分布式ID生成算法在高并发场景下的表现
- **目标用户**：后端开发工程师、性能测试工程师、架构师
- **产品价值**：帮助团队选择最适合业务场景的ID生成方案

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 测试工程师 | 本地访问 | 配置测试参数、执行测试、查看报告 |

### 2.2 功能模块

1. **测试配置页**：算法选择、并发配置、测试参数设置
2. **实时监控页**：测试执行状态、实时QPS/延迟图表
3. **测试报告页**：详细统计数据、唯一性校验结果、历史对比

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 测试配置页 | 算法选择器 | 支持雪花算法、号段模式、随机ID三种算法切换 |
| 测试配置页 | 并发配置 | 设置线程数、测试时长、ID生成数量 |
| 测试配置页 | 高级选项 | 配置机器ID、数据中心ID、号段大小等参数 |
| 实时监控页 | 实时图表 | QPS折线图、延迟分布直方图、进度条 |
| 实时监控页 | 状态面板 | 已生成ID数、当前TPS、平均延迟实时显示 |
| 测试报告页 | 统计概览 | 总QPS、平均/95分位/99分位延迟、总耗时 |
| 测试报告页 | 唯一性校验 | 重复ID检测、冲突数量、重复率统计 |
| 测试报告页 | 导出功能 | 支持JSON/CSV格式导出测试报告 |

## 3. 核心流程

用户在测试配置页面选择ID算法和并发参数，点击开始测试后，后端启动多线程压力测试，前端通过WebSocket实时接收性能数据并展示。测试完成后进行唯一性校验，生成完整测试报告。

```mermaid
flowchart LR
    A["配置测试参数"] --> B["选择ID算法"]
    B --> C["设置并发数/时长"]
    C --> D["启动压力测试"]
    D --> E["实时监控QPS/延迟"]
    E --> F["测试完成"]
    F --> G["唯一性校验"]
    G --> H["生成测试报告"]
    H --> I["导出/保存报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝系 (#165DFF)，体现专业、科技感
- **辅助色**：绿色 (#00B42A) 表示成功，橙色 (#FF7D00) 表示警告，红色 (#F53F3F) 表示错误
- **按钮风格**：圆角8px，悬浮微动效，渐变填充
- **字体**：JetBrains Mono（代码/数据）+ Inter（正文），技术感与可读性平衡
- **布局风格**：卡片式布局，顶部导航，左侧配置区+右侧监控区
- **图标风格**：线性图标，统一24px尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 测试配置页 | 算法卡片 | 三张并排算法卡片，选中态高亮边框+阴影 |
| 测试配置页 | 参数表单 | 分组表单项，滑块+输入框双模式 |
| 实时监控页 | 图表区域 | 大面积图表容器，网格背景，动态数据点 |
| 实时监控页 | 指标卡片 | 四个关键指标卡片，数值放大显示，趋势箭头 |
| 测试报告页 | 统计面板 | 数据表格+可视化图表，对比展示 |
| 测试报告页 | 校验结果 | 成功/失败状态徽章，详细错误列表 |

### 4.3 响应式

- Desktop-first 设计，1440px 为基准宽度
- 平板端：配置区与监控区上下排列
- 移动端：简化图表，折叠配置面板
- 触控优化：按钮最小高度44px
