# 矢量字体生成器 (Vector Font Generator)

从手写样本学习个人字体风格，生成TTF/OTF字体文件。支持中文、英文、数字等字符集。

## 功能特性

- ✍️ **手写样本输入**：支持上传图片或画布手写
- 🎨 **风格学习**：基于PyTorch的VAE模型学习个人字体风格
- 🔍 **轮廓提取**：使用OpenCV进行矢量轮廓提取和优化
- ✨ **字形平滑**：高斯平滑、样条插值、贝塞尔曲线拟合
- 🖋️ **字体生成**：支持TTF和OTF格式输出
- 🌐 **Web界面**：基于Streamlit的友好用户界面

### 🔧 增强功能 (新增)

- 🔍 **中文笔画分解监督**：保持中文字符结构完整性
  - 骨架提取和笔画分解
  - 笔画类型识别（横、竖、撇、捺、点、折、钩、弯、提）
  - 结构约束验证和应用
  - 防止字形变形，保持结构完整

- 📈 **迭代优化拟合**：最小化轮廓拟合误差
  - L-BFGS-B优化算法
  - 贝塞尔曲线控制点迭代优化
  - 参数值自动精调
  - 可配置迭代次数和误差目标

- 🎯 **拐点检测保持**：平滑时保持尖角锐利
  - 局部角度分析拐点检测
  - 拐点强度计算
  - 自适应平滑（拐点区域降低平滑度）
  - RDP简化时强制保留拐点

### 🆕 最新功能 (新增)

- 🎭 **字体风格迁移**：多种字体风格变换
  - **粗体/细体/特粗体**：笔画粗细调整
  - **斜体/倾斜体**：字形倾斜变换
  - **粗斜体**：粗细+倾斜组合
  - **紧凑体/扩展体**：字宽调整
  - **手写体**：添加手写抖动和不规则性
  - 自定义参数调整（粗细、角度、抖动等）
  - 风格插值（两种风格之间平滑过渡）

- 🔀 **字体混合**：两种字体按比例融合
  - **6种混合模式**：线性、缓入、缓出、缓入缓出、平滑阶跃、径向
  - **实时预览**：拖动滑块实时查看混合效果
  - **轮廓对齐**：自动对齐两个字体的轮廓点
  - **尺寸归一化**：统一混合字体的尺寸
  - **渐变序列**：生成从字体A到字体B的过渡动画帧
  - **多字体混合**：支持两种以上字体按权重混合

- 👁️ **字体预览与测试**：输入文本实时预览
  - **4种预览模式**：文本预览、单字预览、字符网格、对比预览
  - **实时渲染**：输入文字立即显示效果
  - **覆盖率分析**：自动检测缺失字符
  - **字距测试**：分析字符对间距
  - **自定义样式**：字号、行间距、字间距、颜色调整
  - **辅助线显示**：基线、边界框、网格线
  - **导出功能**：PNG格式下载预览图

## 技术栈

- **深度学习**: PyTorch (VAE变分自编码器)
- **图像处理**: OpenCV, PIL
- **字体生成**: fontTools
- **平滑算法**: SciPy, RDP算法
- **Web框架**: Streamlit
- **数据处理**: NumPy

## 使用方法

### 方式1：Web界面（推荐）

```bash
python main.py
```

或直接运行：

```bash
streamlit run app.py
```

浏览器会自动打开应用界面。

### 方式2：命令行演示

```bash
python main.py demo
```

### 方式3：Python API

```python
from main import VectorFontGenerator
from config import Config, TrainingConfig

# 创建生成器
generator = VectorFontGenerator(font_name="MyHandwriting")

# 加载样本图片
generator.load_sample_images("data/samples/")

# 学习风格
generator.learn_style()

# 生成目标字符
target_chars = list("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789")
glyphs = generator.generate_glyphs(target_chars, style_strength=0.5)

# 生成字体文件
output_path = generator.create_font_file(glyphs, "output/", file_format='ttf')
print(f"字体已保存到: {output_path}")
```

## 使用流程

### 1. 准备手写样本

将手写字符图片放入 `data/samples/` 目录，图片文件名应为字符本身：
- `a.png`, `b.png`, `c.png` ... (英文字母)
- `1.png`, `2.png`, `3.png` ... (数字)
- `中.png`, `文.png` ... (中文)

**建议**：至少提供3-10个样本字符以获得较好的风格学习效果。

### 2. 启动Web应用

```bash
streamlit run app.py
```

### 3. 在Web界面中操作

1. **手写样本输入**：上传手写字符图片或使用示例字符
2. **风格学习**：从样本中学习个人字体风格
3. **字体生成**：为目标字符集生成个性化字形
4. **下载字体**：生成并下载TTF/OTF字体文件

## 支持的字符集

- **英文小写**: a-z (26个)
- **英文大写**: A-Z (26个)
- **数字**: 0-9 (10个)
- **标点符号**: 常用标点

## 注意事项

1. **样本质量**：手写样本应清晰、对比度高，字符居中
2. **样本数量**：建议至少10个样本字符以获得稳定风格
3. **字符一致性**：保持所有样本的书写风格一致
4. **字体安装**：生成的字体需要安装到系统才能使用

## 常见问题

**Q: 生成的字体在某些应用中不显示？**
A: 确保字体文件正确生成，检查字符映射表(cmap)是否正确。

**Q: 如何提高生成质量？**
A: 增加样本数量，提高样本质量，调整风格强度参数。

**Q: 支持中文吗？**
A: 支持，可以在目标字符集中输入中文字符。

### 增强功能FAQ

**Q: 笔画分解监督有什么作用？**
A: 笔画分解监督可以保持中文字符的结构完整性，防止生成的字形变形、缺笔少画。通过分析样本字符的笔画类型、数量和比例，在生成新字形时应用这些结构约束。

**Q: 迭代优化拟合需要多久？**
A: 迭代优化会增加计算时间，通常每个字形需要几毫秒到几十毫秒。可以通过调整最大迭代次数和目标误差来平衡速度和质量。

**Q: 拐点保持如何工作？**
A: 系统会自动检测轮廓中的尖角（小于设定角度阈值的点），在平滑处理时保护这些点不被过度平滑，保持字形的锐利特征。

**Q: 如何禁用某些增强功能？**
A: 在Web界面的"高级设置"标签页中，可以独立开关这三个功能。在Python API中，可以在创建VectorFontGenerator时通过参数控制。

### 新功能FAQ

**Q: 字体风格迁移支持哪些风格？**
A: 支持9种风格：粗体、细体、特粗体、斜体、倾斜体、粗斜体、紧凑体、扩展体、手写体。每种风格都可以自定义参数。

**Q: 字体混合有什么作用？**
A: 字体混合可以将两种不同风格的字体按比例融合，创造新的字体风格。例如将正常字体和粗体混合，可以得到半粗体效果。

**Q: 混合模式有什么区别？**
A: 线性模式是均匀过渡，缓入模式开始慢后快，缓出模式开始快后慢，缓入缓出模式两端慢中间快，平滑阶跃模式过渡更平滑，径向模式使用正弦曲线过渡。

**Q: 字体预览支持哪些格式导出？**
A: 目前支持PNG格式导出预览图。生成的字体文件支持TTF和OTF格式。

**Q: 如何在Web界面中使用这些新功能？**
A: Web界面新增了三个标签页：
- 🎭 风格迁移：选择目标风格并应用
- 🔀 字体混合：选择两种字体和混合比例
- 👁️ 实时预览：输入文本即时查看效果
