# 图片 CDN 管理台

基于 Angular + NG-ZORRO 构建的响应式图片 CDN 管理前端应用。

## 功能特性

### 1. 图片批量上传
- 支持点击上传和拖拽上传
- 多文件同时选择
- 实时上传进度显示
- 文件格式验证（支持 JPG、PNG、GIF、WebP、BMP）

### 2. 图片编辑功能
- **缩放旋转**：10%-200% 缩放比例，左右 90° 旋转
- **裁剪**：可视化裁剪区域选择
- **水印**：支持自定义水印文字、字体大小、颜色、透明度和位置
- **实时预览**：所有编辑操作实时预览效果

### 3. WebP 格式转换
- 一键转换为 WebP 格式
- 显著减少文件大小（约 25-35%）
- 保持图像质量

### 4. 图片管理列表
- **双视图模式**：网格视图 / 列表视图
- **搜索功能**：按文件名和格式搜索
- **排序功能**：按时间、名称、大小排序
- **批量操作**：预览、编辑、下载、复制链接、删除
- **本地存储**：图片数据持久化保存

## 技术栈

- **框架**：Angular 17.x
- **UI 组件库**：NG-ZORRO (Ant Design for Angular)
- **样式**：SCSS
- **语言**：TypeScript
- **图标**：Ant Design Icons

## 快速开始

### 环境要求

- Node.js >= 18.13.0
- npm >= 8.19.0

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm start
```

访问 `http://localhost:4200` 查看应用。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录。

## 使用说明

### 图片上传

1. 点击上传区域或拖拽图片到上传区域
2. 可选择多个文件同时上传
3. 点击"编辑"按钮对图片进行处理
4. 点击"上传"按钮保存到本地库

### 图片编辑

1. 在上传页面或图片列表中点击"编辑"
2. 在编辑弹窗中进行以下操作：
   - 调整缩放比例和旋转角度
   - 裁剪图片到所需尺寸
   - 添加文字水印（自定义样式）
   - 转换为 WebP 格式
3. 点击"保存"应用修改

### 图片管理

1. 切换到"图片管理"页面
2. 使用搜索框查找特定图片
3. 使用排序按钮调整显示顺序
4. 切换网格/列表视图模式
5. 对图片进行预览、编辑、下载等操作

## 响应式设计

应用完全响应式，支持：
- 桌面端（1920px+）
- 平板设备（768px-1024px）
- 移动设备（320px-768px）
