# Web端视频剪辑工具

一个基于 **FFmpeg + WebAssembly + Vue3** 开发的纯前端视频剪辑工具，所有处理都在浏览器本地完成，无需上传服务器，保护您的隐私安全。

## ✨ 功能特性

- 🎬 **视频裁剪** - 精确裁剪视频片段，支持可视化调整入点出点
- 🔗 **视频拼接** - 支持多个视频片段无缝拼接
- 📝 **添加字幕** - 支持自定义字幕内容、时间、样式（字体大小、颜色）
- ✨ **转场特效** - 8种转场效果（淡入淡出、溶解、擦除、滑动、圆形展开、像素化等）
- 🎵 **背景音乐替换** - 支持替换或添加背景音乐
- 👁️ **实时预览** - 支持视频实时预览、播放控制、音量调节
- 🎚️ **多轨道编辑** - 视频轨、音频轨、字幕轨三轨道独立编辑
- 📤 **视频导出** - 支持自定义分辨率、帧率、质量等参数导出

## 🛠️ 技术栈

- **Vue 3** - 渐进式JavaScript框架
- **Vite** - 下一代前端构建工具
- **Pinia** - Vue3状态管理
- **FFmpeg.wasm** - WebAssembly版FFmpeg，实现浏览器端视频处理
- **WebAssembly** - 高性能浏览器端计算

## 🎯 使用说明

### 1. 导入媒体文件
- 点击左侧媒体库的「+ 导入」按钮，或直接拖拽文件到媒体库区域
- 支持导入视频文件（MP4、WebM、MOV等）和音频文件（MP3、WAV、AAC等）

### 2. 添加到时间轴
- 双击媒体库中的文件，或拖拽文件到时间轴上
- 视频文件会添加到视频轨，音频文件会添加到音频轨

### 3. 视频裁剪
- 点击时间轴上的视频片段选中它
- 在右侧「片段」面板调整入点和出点
- 或者拖拽片段两端的手柄进行可视化裁剪
- 点击「应用裁剪」生成新的裁剪后的视频

### 4. 添加字幕
- 点击字幕轨上的「+」按钮添加字幕
- 在右侧「字幕」面板编辑字幕内容、时间、样式
- 字幕会在预览窗口中实时显示

### 5. 添加转场
- 选中一个视频片段（需要后面还有其他片段）
- 在右侧「转场」面板选择转场效果和时长
- 点击「应用转场」生成带转场效果的视频

### 6. 替换背景音乐
- 在右侧「音频」面板导入背景音乐
- 调整开始时间和音量
- 点击「应用背景音乐」替换原视频音频

### 7. 导出视频
- 点击右上角「导出视频」按钮
- 设置输出参数（文件名、格式、分辨率、帧率等）
- 点击「开始导出」，处理完成后自动下载

## 🔒 隐私保护

所有视频处理操作都在您的浏览器本地完成，文件不会上传到任何服务器。您的视频数据完全由您掌控。

## ⚠️ 注意事项

1. **首次加载**：首次打开时需要下载FFmpeg WebAssembly模块（约25MB），请耐心等待
2. **浏览器要求**：建议使用最新版Chrome、Edge或Firefox浏览器
3. **跨域隔离**：由于WebAssembly安全限制，服务端需要设置COOP和COEP响应头（已在vite配置中处理）
4. **性能**：视频处理是计算密集型操作，处理大文件时可能需要较长时间，建议使用高性能设备
5. **内存**：浏览器对WebAssembly有内存限制，建议处理单个视频文件不超过500MB
