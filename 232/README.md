# 在线协作白板工具

一个基于 Vue3 + Canvas + WebSocket 的实时协作白板应用。

## 功能特性

### 🎨 绘图工具
- **画笔**: 自由绘制，支持自定义颜色和线宽
- **直线**: 绘制直线
- **矩形**: 绘制矩形
- **圆形**: 绘制椭圆/圆形
- **文本**: 双击添加文本
- **橡皮擦**: 擦除内容
- **压力感应**: 根据鼠标移动速度动态调整笔触粗细（模拟压感笔效果）

### 📚 图层管理
- 图层列表显示
- 显示/隐藏图层
- 图层上下移动
- 删除图层

### 🔍 视图控制
- 鼠标滚轮缩放 (10% - 500%)
- Alt + 鼠标拖动平移
- 重置视图

### ⏪ 全局命令队列
- 撤销 (Ctrl+Z)
- 重做 (Ctrl+Y / Ctrl+Shift+Z)
- 远程操作自动入队，全局同步

### 📸 快照功能
- 一键保存白板为PNG图片

### 👥 实时协作
- 多用户同时在线
- 增量同步：只发送绘制的路径点坐标，减少带宽
- 远程光标显示
- 在线用户数显示

### 💾 会话恢复
- 服务器端会话状态保存
- 浏览器本地存储备份
- 重新加入会话自动同步

## 技术改进

### 1. 增量同步机制
画笔绘制时不再等待绘制结束才发送整个图层，而是：
- `startDraw`: 开始绘制时发送图层初始信息
- `appendPoints`: 绘制过程中每30ms批量发送新增的路径点（每批5个点）
- `endDraw`: 绘制结束时确认完成

**优势**：
- 大幅减少单次数据传输量
- 实时性更好，远程用户可以看到绘制过程
- 网络带宽利用率更高

### 2. 全局命令队列
所有操作（添加图层、删除、移动、更新、清空）都作为命令入队：
- 本地操作和远程操作共享同一个命令队列
- 撤销/重做时所有用户同步执行
- 支持命令的正向执行和反向撤销

**支持的命令类型**：
- `addLayer`: 添加图层
- `updateLayer`: 更新图层属性
- `deleteLayer`: 删除图层
- `moveLayer`: 移动图层顺序
- `clear`: 清空画布

### 3. 压力感应模拟
根据鼠标移动速度动态计算笔触粗细：
- 移动越慢 → 笔触越粗（模拟用力按压）
- 移动越快 → 笔触越细（模拟轻扫）
- 范围：基础宽度的 30% - 200%

## 快速开始

### 1. 安装后端依赖并启动服务器

```bash
cd server
npm install
npm start
```

服务器将在 `ws://localhost:8080` 启动。

### 2. 安装前端依赖并启动开发服务器

```bash
cd client
npm install
npm run dev
```

前端应用将在 `http://localhost:3000` 启动。

### 3. 使用说明

1. 打开浏览器访问 `http://localhost:3000`
2. 输入会话ID（留空使用默认会话）
3. 点击"创建新会话"或"加入会话"
4. 开始绘图！

### 4. 多人协作

- 在另一个浏览器窗口/标签页打开相同地址
- 输入相同的会话ID
- 即可看到实时同步的绘图和对方的光标

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |
| Ctrl + Shift + Z | 重做 |
| Alt + 拖动 | 平移画布 |
| 滚轮 | 缩放 |
| 双击 | 添加文本 |

## 技术栈

- **前端**: Vue 3 + Vite + Canvas API
- **后端**: Node.js + ws (WebSocket)
- **同步机制**: 增量点传输 + 全局命令队列
- **本地存储**: localStorage
- **压力感应**: 鼠标速度模拟
