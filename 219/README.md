# 交通流量热力图系统

基于 Python FastAPI 后端和 OpenLayers 前端实现的交通流量热力图分析系统。

## 功能特性

- 📊 **GPS数据上传** - 支持JSON格式的公交车GPS数据导入
- 🗺️ **热力图可视化** - 基于OpenLayers的交互式地图热力图
- ⏱️ **时间窗口分析** - 按5分钟（可配置）时间窗口统计车辆密度
- 🎬 **时间滑动播放** - 支持播放交通流量变化趋势
- 🚦 **拥堵路段识别** - 自动识别和显示高拥堵路段
- ⚙️ **参数可调** - 网格大小、时间窗口、拥堵阈值可配置

## 技术栈

### 后端
- Python 3.8+
- FastAPI - Web框架
- Pandas/Numpy - 数据处理
- Uvicorn - ASGI服务器

### 前端
- OpenLayers 8.2 - 地图引擎
- 原生JavaScript - 交互逻辑
- HTML5/CSS3 - 页面结构和样式

## 快速开始

### 方式一：使用启动脚本（推荐）

1. 双击运行 `start.bat`
2. 等待依赖安装和服务启动
3. 在浏览器中访问 http://localhost:8000

### 方式二：手动启动

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 启动服务：
```bash
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

3. 在浏览器中访问 http://localhost:8000

## 使用说明

### 1. 加载数据

**方式A：加载示例数据**
- 点击「加载示例数据」按钮
- 系统会自动加载内置的北京市公交车示例数据

**方式B：上传自定义数据**
- 输入城市名称
- 选择JSON格式的GPS数据文件
- 点击「上传数据」按钮

### 2. 生成热力图

- 根据需要调整参数：
  - **网格大小** - 热力图网格精度（默认0.001度，约100米）
  - **时间窗口** - 统计时间间隔（默认5分钟）
  - **拥堵阈值** - 判定拥堵的比例阈值（默认0.3）
- 点击「生成热力图」按钮

### 3. 查看和播放

- **时间滑动条** - 拖动查看不同时间段的热力图
- **播放控制** - 点击▶️按钮自动播放变化趋势
- **播放速度** - 选择0.5x/1x/2x/3x播放速度
- **键盘快捷键**：
  - ← → 方向键：切换时间窗口
  - 空格键：播放/暂停

### 4. 查看拥堵路段

- 左侧面板显示Top 10高拥堵路段
- 地图上紫色圆点标记拥堵位置
- 点击圆点查看详细信息

## 数据格式

输入的JSON数据格式示例：

```json
[
  {
    "bus_id": "BUS001",
    "route_id": "1路",
    "longitude": 116.397,
    "latitude": 39.908,
    "timestamp": "2024-05-20T07:00:00"
  }
]
```

支持的字段别名：
- `bus_id` / `vehicleId`
- `route_id` / `routeId` / `line`
- `longitude` / `lng`
- `latitude` / `lat`
- `timestamp` / `time`

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/upload` | POST | 上传GPS数据文件 |

## 核心算法

### 智能网格边界计算 (`backend/utils.py:11-33`)
1. 根据输入数据的经纬度最大最小值确定范围
2. 自动添加0.01度的边距padding
3. 对于数据范围过小的区域自动扩展到最小范围（0.03度）
4. 确保热力图有合适的显示区域

### 后端瓦片生成 (`backend/utils.py:279-341`)
1. 基于PIL创建RGBA透明背景图片
2. 根据密度值渲染不同颜色的圆点（绿→黄→橙→红）
3. 使用Scipy进行高斯模糊处理实现平滑效果
4. 生成PNG格式的静态图片瓦片

### 多线程预生成缓存 (`backend/main.py:202-236`)
1. 生成热力图时自动启动后台线程
2. 使用ThreadPoolExecutor并行处理多个时间窗口
3. 实时更新预生成进度（0-100%）
4. 内存缓存所有生成的图片

### 双缓冲渲染 (`frontend/app.js:85-159`)
1. 主图层（front buffer）：当前显示的热力图
2. 后缓冲区（back buffer）：预加载的下一帧
3. 切换时通过opacity渐变实现平滑过渡（淡入淡出）
4. 过渡完成后交换前后缓冲区

### 前瞻预加载策略 (`frontend/app.js:161-193`)
1. 显示当前帧的同时，预加载后续3帧
2. 使用Image对象异步加载图片
3. Canvas转DataURL实现内存缓存
4. 避免重复加载和网络请求

### 智能缓存管理 (`frontend/app.js:195-220`)
1. 保留当前帧前后5帧的缓存
2. 超出范围的旧缓存自动清理
3. 内存使用优化，防止内存泄漏
4. 循环播放时重新利用已有缓存

### 网格密度计算
1. 根据经纬度范围创建网格（默认0.001度）
2. 将每个GPS点匹配到对应网格
3. 统计每个网格内的车辆数量
4. 计算相对密度（当前计数/最大计数）

### 拥堵路段识别
1. 按线路分组统计各网格的车辆分布
2. 计算该线路在每个网格的车辆占比
3. 占比超过阈值且车辆数≥3则判定为拥堵

### 时间窗口处理
1. 从最早时间开始，按设定窗口大小划分
2. 每个窗口独立统计网格密度
3. 生成时间序列的热力图数据

## 注意事项

1. 确保经纬度坐标系为WGS84
2. 时间戳格式建议使用ISO 8601
3. 建议数据量适中（1000-10000条）以保证性能
4. 首次使用请先加载示例数据体验功能
