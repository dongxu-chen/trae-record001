## 1. 产品概述
数据映射工具是一个可视化的Web应用，帮助用户通过拖拽连线的方式将源数据（Excel/CSV/JSON）映射到目标数据模型，支持灵活的数据转换，实现数据格式的快速转换和导出。

- **解决问题**：传统数据映射需要编写代码或复杂的Excel公式，效率低下且易出错
- **目标用户**：数据分析师、业务人员、开发人员
- **核心价值**：可视化操作、零代码、灵活转换、批量处理

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 普通用户 | 无需注册 | 全部功能使用权限 |

### 2.2 功能模块
1. **数据导入模块**：支持Excel、CSV、JSON格式文件上传与解析
2. **可视化映射模块**：基于React Flow的拖拽连线式字段映射
3. **转换函数模块**：拼接、拆分、格式化、查表等数据转换
4. **预览导出模块**：批量数据预览和多种格式导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主工作台 | 文件上传区 | 拖拽或点击上传Excel/CSV/JSON文件 |
| 主工作台 | 源数据面板 | 展示解析后的源数据字段和预览 |
| 主工作台 | 目标模型面板 | 配置和展示目标数据模型字段 |
| 主工作台 | 映射画布 | React Flow拖拽连线进行字段映射 |
| 主工作台 | 转换函数面板 | 配置字段转换规则和参数 |
| 主工作台 | 数据预览区 | 批量预览映射转换后的数据 |
| 主工作台 | 导出操作区 | 支持Excel/CSV/JSON格式导出 |

## 3. 核心流程
用户上传数据文件 → 系统解析并展示源字段 → 用户配置目标模型 → 拖拽连线建立映射关系 → 配置转换函数 → 预览映射结果 → 导出最终数据

```mermaid
flowchart LR
    A["上传数据文件"] --> B["解析源数据"]
    B --> C["展示源字段"]
    D["配置目标模型"] --> E["展示目标字段"]
    C --> F["拖拽连线映射"]
    E --> F
    F --> G["配置转换函数"]
    G --> H["预览映射结果"]
    H --> I["导出数据"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色系（#1e40af - #3b82f6），专业、稳重
- **辅助色**：青色（#06b6d4）用于交互元素，琥珀色（#f59e0b）用于警告
- **按钮风格**：圆角8px，悬停时有阴影和轻微放大效果
- **字体**：Inter 字体族，层级清晰（标题600、正文400、辅助300）
- **布局风格**：三栏布局 + 底部预览区，卡片式设计，玻璃拟态效果
- **图标风格**：Lucide 线性图标，简洁现代

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主工作台 | 文件上传区 | 拖拽区域、文件图标、上传按钮、格式说明 |
| 主工作台 | 源/目标面板 | 字段列表、搜索框、字段类型标签、拖拽手柄 |
| 主工作台 | 映射画布 | React Flow节点、贝塞尔曲线连线、节点标签、缩放控制 |
| 主工作台 | 转换面板 | 函数选择器、参数配置、实时预览、添加/删除按钮 |
| 主工作台 | 预览区 | 表格展示、分页控制、行选择、列调整 |
| 主工作台 | 导出区 | 格式选择、文件名输入、导出按钮、进度提示 |

### 4.3 响应式
- 桌面端优先（1280px+）：完整三栏布局
- 平板端（768px-1279px）：左右面板可折叠，画布自适应
- 移动端（<768px）：垂直堆叠布局，简化操作
