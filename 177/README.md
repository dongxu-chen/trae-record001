# 股票量价因子分析平台 Pro

一个基于 Python + Streamlit + TA-Lib 的专业股票量价因子分析平台，支持**多股票对比**、**因子有效性分析**和**策略回测引擎**。

## ✨ 核心功能

### 🎯 四大工作模式

| 模式 | 功能说明 |
|------|----------|
| **单股票深度分析** | 单只股票的完整技术分析，K线、RSI、MACD、KDJ、成交量 |
| **多股票对比** | 多只股票因子走势对比、累计收益对比、指标汇总 |
| **因子有效性分析** | IC值计算、热力图、分位数收益分析，评估因子预测能力 |
| **策略回测引擎** | 基于因子信号的策略回测，输出净值曲线和详细交易记录 |

### 📊 因子计算（通达信默认参数）
- **RSI (6/12/24)**: 三条RSI线，超买80/超卖20
- **MACD (12/26/9)**: DIF/DEA/MACD柱，通达信标准算法
- **KDJ (9/3/3)**: 随机指标，通达信标准平滑算法
- **布林带 (20/2)**: 20日均线±2倍标准差
- **成交量**: 5日均量线，量比分析
- **动量/波动率**: MOM动量、ATR真实波幅

### 🔬 因子有效性分析
- **IC值计算**: Spearman秩相关系数，衡量因子预测能力
- **IC热力图**: 可视化各因子在不同预测周期的表现
- **分位数收益**: 按因子值分组，查看分组收益单调性
- **统计显著性**: P值检验，评估因子有效性

### 💹 策略回测引擎
- **多策略方向**: 做多高分位、做多低分位、多空对冲
- **可调整参数**: 持仓周期、分位数数量、初始资金
- **绩效指标**: 总收益、年化收益、夏普比率、最大回撤、波动率
- **详细交易记录**: 每笔交易的入场/出场、盈亏、收益率
- **CSV导出**: 交易记录一键下载

### 操作流程

#### 1. 选择工作模式
在左侧边栏选择工作模式：
- **单股票深度分析**: 快速查看单只股票技术面
- **多股票对比**: 横向比较多只股票的因子和表现
- **因子有效性分析**: 科学评估因子的预测能力
- **策略回测引擎**: 验证基于因子的交易策略

#### 2. 选择股票
- **预设股票**: 从下拉菜单快速选择（贵州茅台、五粮液、平安银行等）
- **自定义**: 在文本框输入股票代码，每行一个
- **股票代码格式**:
  - A股：`600519.SS`（上交所）、`000858.SZ`（深交所）
  - 美股：`AAPL`（苹果）、`MSFT`（微软）
  - 港股：`0700.HK`（腾讯）

#### 3. 设置参数
- 时间区间：默认回测3年数据
- 因子参数：使用通达信默认值，可按需调整
- 回测设置：持仓周期、分位数数量、策略方向

#### 4. 运行分析
点击"🚀 开始分析"按钮，等待数据获取和因子计算完成。

## 📖 功能详解

### 单股票深度分析
- **价格走势**: K线图叠加布林带
- **RSI指标**: 三条RSI线（6/12/24），超买超卖区间标注
- **MACD指标**: DIF、DEA、MACD柱，金叉死叉一目了然
- **KDJ指标**: K、D、J三线，超买超卖区间
- **成交量**: 量柱叠加均量线
- **因子数据表**: 最近50个交易日的因子值明细

### 多股票对比
- **因子对比图**: 同一因子在多只股票上的走势对比
- **最新值排序**: 按因子值降序排列，快速定位极值
- **累计收益对比**: 所有股票的累计收益率曲线
- **指标汇总表**: 年化收益、波动率、最大回撤、最新因子值

### 因子有效性分析
#### IC值热力图
- 横轴：预测周期（1天/5天/10天）
- 纵轴：因子名称
- 颜色：IC值大小，绿色为正，红色为负
- **解读**：
  - IC > 0.05：因子有一定预测能力
  - IC > 0.1：因子预测能力较强
  - P值 < 0.05：统计显著

#### 分位数收益分析
- 将所有样本按因子值从小到大分为N组
- 计算每组的平均未来收益率
- **理想形态**：收益随分位数单调递增或递减
- **柱状图**：绿色表示正收益，红色表示负收益

### 策略回测引擎
#### 策略逻辑
1. 每天按因子值将股票分为N个分位数
2. 根据策略方向发出交易信号：
   - `long_high`: 买入因子值最高的分位
   - `long_low`: 买入因子值最低的分位
   - `long_short`: 做多最高分位，做空最低分位
3. 持有指定天数后平仓
4. 重复上述过程

#### 输出结果
- **净值曲线**: 策略净值 vs 持有收益
- **绩效汇总**: 所有股票的回测指标
- **交易统计**: 总交易次数、胜率、总盈亏、平均单笔收益
- **交易记录**: 每笔交易的详细信息（可下载CSV）
- **单股详情**: 选择个股查看详细回测曲线

## 🧪 因子有效性评估标准

### IC值（Information Coefficient）
| IC绝对值 | 评价 | 说明 |
|---------|------|------|
| < 0.02 | 无效 | 因子几乎没有预测能力 |
| 0.02 - 0.05 | 弱有效 | 有一定预测能力，需结合其他因子 |
| 0.05 - 0.1 | 有效 | 预测能力较强，可用于构建策略 |
| > 0.1 | 强有效 | 预测能力很强，优质因子 |

### 分位数收益单调性
- ✅ **好因子**：收益随分位数单调递增（或递减）
- ❌ **坏因子**：收益无规律，中间高两边低
- ⚠️ **需注意**：最高分位与最低分位的收益差越大越好

### 统计显著性
- P值 < 0.05：在95%置信水平下显著
- P值 < 0.01：在99%置信水平下显著
- 样本量 > 100：结果更可靠

## 💡 使用建议

### 因子研究流程
1. **初步筛选**: 用因子有效性分析批量评估多个因子
2. **参数优化**: 对有效因子进行参数敏感性测试
3. **策略构建**: 选择有效因子构建交易策略
4. **回测验证**: 用策略回测引擎验证策略效果
5. **样本外测试**: 用不同时间段和股票池验证稳健性

### 注意事项
1. **过拟合风险**: 避免过度优化参数，保持策略简洁
2. **样本偏差**: 回测结果可能受特定市场环境影响
3. **交易成本**: 实际收益需扣除手续费和滑点
4. **风险控制**: 建议加入止损、仓位管理等风控措施
