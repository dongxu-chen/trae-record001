## 1. 产品概述

Web端LED字幕滚动组件——一个高度可定制的实时LED字幕滚动效果生成器，支持自定义文字、字体、颜色、滚动速度、背景特效、多方向滚动和多行显示，提供所见即所得的实时预览体验。面向内容创作者、活动策划者、直播主播等需要LED字幕效果的用户。

## 2. 核心功能

### 2.1 功能模块

1. **实时预览区**：LED字幕滚动效果的实时Canvas渲染预览，支持全屏展示
2. **控制面板**：文字编辑、样式配置、滚动设置、背景特效等全部参数调节

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 实时预览区 | Canvas渲染LED字幕滚动效果，实时反映所有配置变更，支持全屏播放 |
| 主页面 | 文字编辑模块 | 多行文字输入，支持添加/删除行，每行可独立配置内容 |
| 主页面 | 字体与颜色模块 | 字体选择（多种预设LED字体）、文字颜色选择（ColorPicker）、背景颜色选择 |
| 主页面 | 滚动设置模块 | 滚动方向（左→右、右→左、上→下、下→上）、滚动速度滑块、滚动模式（连续/单次） |
| 主页面 | 背景特效模块 | 粒子效果、矩阵雨、霓虹光晕、星空闪烁等背景特效选择 |
| 主页面 | 预设模板模块 | 预设多种LED效果模板（演唱会、新闻播报、公告栏等），一键应用 |

## 3. 核心流程

用户打开页面 → 在控制面板中输入文字内容 → 调整字体/颜色/速度/方向等参数 → 实时预览区同步显示效果 → 选择背景特效增强视觉 → 可一键应用预设模板快速配置 → 全屏播放最终效果

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深黑底色(#0a0a0f)搭配霓虹绿(#00ff88)作为核心强调色，辅以霓虹粉(#ff0088)和霓虹蓝(#0088ff)
- **按钮风格**：圆角微3D按钮，hover时发光效果，匹配LED霓虹美学
- **字体**：显示字体使用"Orbitron"（科技感LED风格），UI字体使用"Rajdhani"
- **布局风格**：左侧大面积实时预览区 + 右侧折叠式控制面板，桌面优先
- **图标风格**：线性图标，霓虹风格，来自lucide-react
- **整体氛围**：赛博朋克/霓虹科技风格，深色背景配发光元素，营造真实LED屏幕观感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 实时预览区 | 深色背景Canvas，字幕发光效果，边框霓虹线条装饰，全屏按钮 |
| 主页面 | 文字编辑 | 多行文本输入框，每行带删除按钮，底部添加行按钮，发光输入框边框 |
| 主页面 | 字体与颜色 | 字体下拉选择器，颜色选择器（ColorPicker），色板预设 |
| 主页面 | 滚动设置 | 方向选择4向按钮组，速度滑块（带数值显示），模式切换开关 |
| 主页面 | 背景特效 | 特效卡片网格选择，特效强度滑块，特效颜色选择 |
| 主页面 | 预设模板 | 水平滚动模板卡片，缩略图预览，一键应用 |

### 4.3 响应式

- 桌面优先设计（1920×1080为基准）
- 大屏：左右分栏布局（预览区70% + 控制面板30%）
- 中屏：上下布局（预览区上方 + 控制面板下方Tab切换）
- 小屏：全屏预览 + 底部抽屉式控制面板

### 4.4 3D场景指引

不适用，本项目为2D Canvas渲染。
