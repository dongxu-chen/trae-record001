# 💳 信用卡消费分类系统

基于 Python + 机器学习 + 规则引擎的智能信用卡消费分类系统，支持自动识别消费类别、生成月度报表、异常检测等功能。

## ✨ 功能特性

### 1. 消费分类
- **精确匹配**: 基于内置商户库进行精确匹配
- **模糊匹配**: 使用 fuzzywuzzy 进行商户名模糊匹配
- **机器学习分类**: 基于 TF-IDF + 朴素贝叶斯的文本分类模型
- **规则引擎**: 支持用户自定义分类规则

### 2. 商户库管理
- 内置 500+ 常见商户，覆盖 5 大类别
- 支持商户的增删改查
- 支持关键词搜索

### 3. 规则引擎
- 支持多种条件类型：商户包含、金额范围、时间范围、星期几等
- 支持多种动作：设置分类、标记异常、添加标签
- 支持规则优先级和启用/禁用

### 4. 异常检测
- 异常金额检测（Z-score 方法）
- 高频消费检测
- 异常时段消费检测
- 新商户大额消费检测

### 5. 月度报表
- 消费概览统计
- 类别消费分析
- 每日消费趋势
- TOP 10 商户统计
- Excel 报表导出

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
streamlit run app.py
```

### 3. 使用系统

1. 打开浏览器访问 http://localhost:8501
2. 在【数据导入】页面上传 `sample_transactions.csv` 或手动输入交易
3. 在【消费分类】页面查看分类结果
4. 在【月度报表】页面生成统计报表
5. 在【异常检测】页面检测异常交易
6. 在【商户库管理】页面管理商户
7. 在【规则引擎】页面配置自定义规则

## 🔧 分类策略优先级

系统采用多层级分类策略，按以下优先级执行：

1. **精确匹配** (最高优先级) - 商户库精确匹配
2. **模糊匹配** - 商户库模糊匹配（置信度 > 70%）
3. **规则匹配** - 用户自定义规则
4. **机器学习模型** - TF-IDF + 朴素贝叶斯
5. **默认分类** - 归类为"其他"

## 📝 自定义规则示例

### 规则1：大额消费标记
- **条件**: 金额 > 5000
- **动作**: 标记为异常
- **优先级**: 10

### 规则2：深夜餐饮
- **条件**: 时间在 22:00-06:00 且商户包含"餐厅/烧烤/火锅"
- **动作**: 设置分类为"餐饮"
- **优先级**: 5
