# 格子玻尔兹曼流体模拟可视化工具 (完整版)

基于格子玻尔兹曼方法(LBM)的交互式流体模拟可视化工具，包含高级物理模型和可视化功能。

---

## ✨ 最新功能 (v2.0)

### 🔷 多相流模拟
- 气液两相流模拟，基于颜色函数法
- 相界面自动捕捉（相场方法）
- 表面张力模型（CSF连续表面力）
- 可调节密度比（液/气 = 2~20）
- 可调节表面张力系数
- 预设液滴、液柱场景

### 🔷 流固耦合 (FSI)
- 动量交换法计算流体力
- 刚体运动方程求解（平动+转动）
- 可配置刚体密度和半径
- 支持固定障碍物和可动刚体
- 实时显示刚体位置、速度、受力
- 刚体-墙壁碰撞检测与反弹

### 🔷 粒子追踪与流线
- 示踪粒子随流场运动
- 双线性插值速度采样
- 可配置粒子数量（100~5000）
- 可配置释放速率和流线长度
- 流线渐变尾迹效果
- 粒子生命周期管理

## 🔬 算法说明

### 多相流 - 颜色函数法
- 两套分布函数 `f1` 和 `f2` 分别模拟液相和气相
- 相场函数 `C = f1 / (f1 + f2)` 表示液相占据率
- 界面识别：`φ = C(1-C)`
- 表面张力：CSF连续表面力模型
  ```
  F = σ κ n
  κ = -∇·(∇C/|∇C|)  (曲率)
  n = ∇C / |∇C|      (法向量)
  ```
- 平衡态分布函数包含表面张力项

### 流固耦合 - 动量交换法
- 碰撞前后动量差计算流体力：
  ```
  F_i = (f_i - f'_i) * c_i
  F = Σ F_i
  τ = Σ r × F_i
  ```
- 刚体运动方程：
  ```
  m dv/dt = F
  I dω/dt = τ
  ```
- 动网格技术：障碍物随刚体位置更新
- 刚体边界条件考虑刚体速度影响

### 粒子追踪
- 粒子运动方程：`dx/dt = u(x(t), t)`
- 速度双线性插值：
  ```
  u(x,y) = (1-wx)(1-wy) u(x0,y0) + wx(1-wy) u(x0+1,y0)
         + (1-wx)wy u(x0,y0+1) + wxwy u(x0+1,y0+1)
  ```
- 流线渲染：GL_LINES带透明度渐变
- 粒子生命周期管理，自动回收重用

## 💡 使用建议

### 多相流模拟技巧
1. 先启动基本流场，再启用多相流
2. 液滴场景建议密度比设为5-10
3. 表面张力系数过大会导致数值不稳定
4. 相界面显示用黄色高亮，便于观察

### 流固耦合技巧
1. 先添加固定刚体形成稳定流场
2. 再添加可动刚体观察流体驱动效果
3. 刚体密度接近流体时运动更明显
4. 刚体太小可能被流体直接推出域

### 粒子追踪技巧
1. 先暂停模拟，调整粒子参数
2. 流线长度100-200效果最佳
3. 释放速率10-20/帧比较流畅
4. 粒子数过多会影响渲染性能

## 常见问题

**Q: 多相流模拟发散怎么办？**
A: 降低密度比，减小表面张力系数，开启稳定化处理

**Q: 刚体运动不明显？**
A: 增大入流速度，减小刚体密度，增大刚体半径

**Q: 流线显示不连贯？**
A: 增加流线长度，降低粒子释放速率，提高每帧步数

**Q: 界面卡顿？**
A: 减少粒子数量，关闭部分可视化，使用GPU加速
