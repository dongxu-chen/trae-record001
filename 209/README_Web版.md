# 电商用户画像分析系统（Web版）

## 功能特性

### 📈 1. 总览面板
- 四类用户数量统计卡片
- 用户分群占比饼图
- 各用户群特征对比柱状图

### 📉 2. 趋势分析
- **月度用户数量变化**：展示近12个月各类别用户数量趋势
- **业务活动节点标注**：618大促、双11、年货节等活动节点用虚线标注
- **用户群结构变化**：堆叠面积图展示用户结构演变
- **业务活动日历**：展示所有营销活动及其影响程度

### ⚙️ 3. 在线规则配置
- **基础配置**：分析日期、偏好计算窗口、数据分区数
- **用户分类规则**：可视化调整每类用户的阈值条件
  - 最近活跃天数范围
  - 消费能力最小值
  - 活跃度最小值
- **权重配置**：订单数、浏览数、评论数的权重系数
- **一键重新计算**：规则修改后实时重新计算用户画像

### 👥 4. 用户明细与导出
- **多条件筛选**：按用户群、活跃度、消费金额筛选
- **分页展示**：20条/页，支持翻页
- **CSV导出**：按筛选条件导出用户明细
- **完整字段**：用户ID、用户群、消费、订单、活跃度、偏好品类等

## 分类规则配置说明

在 `classification_rules.json` 中配置：

```json
{
  "segments": [
    {
      "name": "高价值用户",
      "conditions": {
        "recency_max": 30,      // 最近活跃≤30天
        "consumption_min": 3.5, // 消费能力≥3.5
        "activity_min": 3.0     // 活跃度≥3.0
      },
      "priority": 1  // 匹配优先级（数字越小越先匹配）
    }
  ]
}
```

## 性能优化特性

| 优化手段 | 说明 |
|---------|------|
| 数据重分区 | 按user_id哈希分区，避免数据倾斜 |
| 广播变量 | 小表（品类维度表）广播优化Join |
| DataFrame Cache | 常用数据内存缓存 |
| 自适应AQE | Spark SQL自适应执行 |
| 内存导出 | CSV直接在内存生成，不写磁盘 |

## 使用流程

### 常规分析流程
1. 启动服务 → 访问首页
2. 查看「总览」了解当前用户结构
3. 点击「趋势分析」观察历史变化和活动影响
4. 在「规则配置」中调整阈值
5. 点击「重新计算画像」查看新规则效果
6. 在「用户明细」中筛选并导出目标用户

### A/B测试流程
1. 在JSON配置中设置ab_test.enabled=true
2. 配置对照组control_group的规则
3. 配置实验组experimental_group规则（或使用主配置）
4. 使用Jupyter Notebook中的A/B测试模块对比分析

## 常见问题

**Q: Spark启动慢？**
A: 首次启动需要初始化SparkSession，约需10-30秒

**Q: 如何连接真实Hive数据？**
A: 修改 `generate_mock_data()` 函数，替换为：
```python
return spark.sql("SELECT * FROM hive_orders_table")
```

**Q: 导出CSV在哪里？**
A: 导出时直接通过浏览器下载，不会在服务器保存文件

**Q: 如何添加新的用户群？**
A: 在JSON配置的segments数组中新增条目，设置priority确保匹配顺序正确
