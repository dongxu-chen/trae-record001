## 1. 产品概述
分布式事务监控平台（DTMonitor）是一个面向微服务架构的全链路事务监控与诊断系统。它实时监控Seata框架下TCC、SAGA、AT等模式的事务状态，记录事务执行链路、异常与回滚，提供超时告警、链路可视化与异常诊断能力。
- 目标用户：微服务架构下的后端开发工程师、运维工程师、架构师
- 核心价值：降低分布式事务故障定位时间，提升系统可靠性

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 开发工程师 | 统一认证 | 查看事务、诊断异常、查看链路 |
| 运维工程师 | 统一认证 | 管理告警规则、确认告警、查看仪表盘 |
| 架构师 | 统一认证 | 全局事务分析、模式统计、趋势洞察 |

### 2.2 功能模块
1. **监控仪表盘**：事务总量/活跃/异常统计、模式分布、状态分布、趋势图
2. **事务列表页**：按模式/状态/应用筛选、时间范围查询、分页浏览
3. **事务详情页**：事务基本信息、分支事务列表、事件时间线、链路DAG图
4. **链路可视化页**：事务执行链路DAG图、Span时间线、服务调用拓扑
5. **告警管理页**：未确认告警列表、告警确认、告警规则管理
6. **异常诊断页**：诊断报告、根因分析、修复建议

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程
用户登录后进入仪表盘，查看全局事务概览。通过事务列表筛选异常事务，点击进入详情页查看分支、事件与链路。发现异常后点击诊断按钮生成诊断报告，查看根因与修复建议。告警页面管理超时/回滚告警，运维确认告警后消除通知。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝黑（#0B1120）背景 + 青色（#06D6A0）高亮 + 琥珀色（#FFB800）警告 + 红色（#EF4444）异常
- 按钮风格：圆角微凸，半透明玻璃质感
- 字体：JetBrains Mono（数据/代码）+ Outfit（标题/正文）
- 布局：左侧导航 + 主内容区，卡片式布局
- 图标：Lucide图标库，线性风格
- 整体风格：暗色系监控仪表盘，工业科技感

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 统计卡片 | 渐变背景卡片、数字计数动画、图标 |
| 仪表盘 | 分布图 | 半透明环形图、标签图例 |
| 仪表盘 | 趋势图 | 面积折线图、渐变填充、网格线 |
| 事务列表 | 筛选栏 | 下拉选择器、日期范围选择器、搜索按钮 |
| 事务列表 | 数据表格 | 暗色表格、状态标签颜色、行hover高亮 |
| 事务详情 | 链路DAG | SVG有向图、节点颜色编码、边动画 |
| 链路可视化 | Span瀑布 | 横向时间条、颜色编码服务、Tooltip |
| 告警管理 | 告警列表 | 严重度颜色标签、确认按钮 |
| 异常诊断 | 诊断报告 | 严重度指示器、折叠面板、建议列表 |

### 4.3 响应式
- 桌面优先设计，1920px为基准
- 平板适配：侧边栏折叠为图标模式
- 手机端：简化视图，核心数据优先
