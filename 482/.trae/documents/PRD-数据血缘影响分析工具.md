## 1. 产品概述

数据血缘影响分析工具是一款面向数据工程师、数据分析师和数据治理人员的Web应用，用于分析字段级别的数据血缘关系，快速评估字段变更对下游报表和ETL任务的影响范围。

- **核心价值**：解决数据变更前无法准确评估影响范围的痛点，降低数据变更风险，提升数据治理效率
- **目标用户**：数据工程师、数据分析师、数据治理专员、BI开发人员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 数据工程师 | 无需登录 | 多数据源配置、血缘分析、影响范围导出 |
| 数据分析师 | 无需登录 | 字段查询、血缘可视化、报表影响分析 |

### 2.2 功能模块
1. **首页/分析页**：字段搜索、数据源选择、血缘分析入口
2. **血缘可视化**：影响链路图展示、节点交互、链路追踪
3. **影响范围详情**：下游任务列表、报表列表、影响统计
4. **数据源管理**：多数据源配置（Hive、MySQL）、连接测试
5. **结果导出**：Excel/JSON格式导出影响分析报告

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 搜索模块 | 字段名称输入、数据源多选、搜索按钮 |
| 主页面 | 血缘图谱 | 力导向图展示血缘链路、节点拖拽、缩放平移 |
| 主页面 | 详情面板 | 节点信息展示、影响统计、上下游列表 |
| 主页面 | 数据源管理 | 数据源增删改查、连接测试、元数据同步 |
| 主页面 | 导出功能 | 支持Excel/JSON格式导出分析结果 |

## 3. 核心流程

用户输入字段名称并选择数据源 → 系统解析SQL脚本提取血缘关系 → 构建字段依赖图谱 → 可视化展示影响链路 → 用户可导出分析报告

```mermaid

    A["输入字段名称"] --> B["选择数据源"]
    B --> C["点击分析按钮"]
    C --> D["解析SQL脚本"]
    D --> E["构建血缘图谱"]
    E --> F["可视化展示"]
    F --> G["交互探索"]
    G --> H["导出报告"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色 (#165DFF) 代表专业和技术感
- **辅助色**：青绿色 (#00B42A) 表示成功、橙色 (#FF7D00) 表示警告
- **中性色**：深灰 #1D2129、中灰 #4E5969、浅灰 #C9CDD4
- **按钮风格**：圆角矩形，主按钮深蓝色填充，悬停有微妙阴影效果
- **字体**：使用 JetBrains Mono 等宽字体展示代码和字段名，Inter 作为界面字体
- **布局风格**：三栏布局（左侧导航+中间图谱+右侧详情），卡片式设计
- **图标风格**：线性简约图标，统一24px尺寸

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 顶部导航 | Logo、数据源下拉、主题切换、导出按钮 |
| 主页面 | 搜索区域 | 搜索框、数据源多选、分析按钮、历史记录 |
| 主页面 | 图谱区域 | 力导向图、缩放控制、全屏切换、图例说明 |
| 主页面 | 详情面板 | 节点信息卡片、影响统计表、上下游列表 |
| 主页面 | 数据源弹窗 | 表单输入、连接测试按钮、保存取消 |

### 4.3 响应式
- **Desktop-first**：1920px为主要设计尺寸
- **平板适配**：1024px时详情面板改为底部滑出
- **移动适配**：768px以下简化为单栏布局，图谱区域优先展示

### 4.4 动效设计
- 图谱节点悬停放大效果
- 链路高亮渐变色动画
- 面板滑入滑出过渡动画
- 搜索结果渐显效果
- 节点展开/折叠的平滑过渡
