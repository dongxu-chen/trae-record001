# 仓库货位分配优化系统

基于遗传算法的仓库货位分配优化系统，通过优化商品存放位置来减少拣货路径，提高仓库运营效率。

## 功能特性

- 🏗️ **仓库建模**: 支持自定义仓库通道数、货位数、层数
- 📦 **商品管理**: 考虑商品尺寸、重量、出库频率、分类等属性
- 🧬 **遗传算法优化**: 使用 DEAP 库实现多目标优化
  - 周转率优化：高频商品靠近出库台
  - 相关性优化：相关商品相邻存放
  - 路径优化：减少拣货总距离
- 🚚 **路径模拟**: 三种拣货路径算法
  - 最近邻居法 (Nearest Neighbor)
  - TSP 2-opt 优化
  - S型路径 (S-shape)
- 📊 **3D可视化**: 使用 Plotly 实现交互式3D货位布局
- 📈 **效果对比**: 直观展示优化前后的拣货效率提升

## 使用说明

### 1. 初始化数据

在左侧侧边栏配置参数后，点击「初始化数据」：

- **仓库配置**: 通道数量、每通道货位数、层数
- **商品配置**: 商品数量、订单数量
- **遗传算法参数**: 种群大小、迭代次数、交叉/变异概率
- **优化权重**: 周转率、相关性、距离的权重

### 2. 货位分配策略

系统提供三种货位分配策略进行对比：

| 策略 | 说明 |
|------|------|
| 随机分配 | 随机分配货位，作为基准对比 |
| 周转率优先 | 高周转商品优先靠近出库台 |
| 遗传算法优化 | 多目标综合优化 |

### 3. 优化算法参数说明

- **种群大小 (Population Size)**: 每代的个体数量，通常 50-200
- **迭代次数 (Generations)**: 进化代数，通常 50-300
- **交叉概率 (Crossover Probability)**: 个体交叉的概率，建议 0.5-0.8
- **变异概率 (Mutation Probability)**: 个体变异的概率，建议 0.1-0.3

## 优化目标函数

系统使用加权求和的多目标优化：

```
总适应度 = w1 * 周转率得分 + w2 * 相关性得分 + w3 * 距离得分
```

其中：
- **周转率得分**: 高频商品靠近出库台的程度
- **相关性得分**: 相关商品的邻近程度
- **距离得分**: 模拟拣货路径的倒数（越小越好）
