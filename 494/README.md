# 股票技术指标回测平台

一个基于 Python + Backtrader + Plotly + Streamlit 的股票技术指标回测平台，支持策略回测、参数优化和可视化分析。

## ✨ 最新更新

### 🔬 贝叶斯优化
- 使用高斯过程和随机森林进行智能参数搜索
- 比网格搜索快5-10倍，大幅减少迭代次数
- 支持自定义迭代次数（推荐20-50次）
- 自动平衡探索与利用

### 💹 滑点模型与手续费修正
- 支持百分比滑点设置（默认0.1%）
- 精确计算每笔交易的滑点成本
- 总手续费和平均滑点统计
- 更真实的回测结果

### ⏱️ 时间戳精确对齐
- 交易信号使用精确时间戳记录
- 基于DataFrame索引精确匹配K线位置
- 避免信号错位，确保可视化准确性
- 支持子分钟级数据对齐

## 使用说明

1. **配置回测参数**（左侧边栏）:
   - 输入股票代码（如 `600519.SS` 表示贵州茅台，`AAPL` 表示苹果）
   - 选择回测时间范围
   - 设置初始资金、手续费率和滑点
   - 选择策略并调整参数

2. **运行回测**:
   - 点击「运行回测」按钮
   - 查看回测结果和可视化图表
   - 在「交易成本详情」中查看手续费和滑点统计

3. **参数优化**（推荐使用贝叶斯优化）:
   - 展开「参数优化」面板
   - 选择优化方法（**贝叶斯优化**/网格搜索/遗传算法）
   - 选择优化目标（夏普比率、总收益率等）
   - 点击「开始优化」
   - 优化完成后可「应用最佳参数」

4. **贝叶斯优化使用建议**:
   - 迭代次数: 20-50次（比网格搜索快得多）
   - 基模型选择: 
     - 高斯过程(GP): 适合小参数空间，精度高
     - 随机森林: 适合大参数空间，速度快

4. **查看结果**:
   - **收益曲线**: 资产净值曲线、月度收益热力图
   - **交易信号**: K线图、买卖点标记、交易记录
   - **回撤分析**: 回撤曲线、回撤统计
   - **交易分析**: 盈亏分布、累计盈亏
   - **参数优化**: 最佳参数、参数热力图

## 策略说明

### 双均线策略
- **原理**: 当短期均线上穿长期均线（金叉）时买入，当短期均线下穿长期均线（死叉）时卖出
- **参数**: 快速均线周期、慢速均线周期
- **优点**: 趋势跟踪，简单易懂
- **缺点**: 在震荡市场中容易产生假信号

### RSI策略
- **原理**: 当RSI低于超卖阈值时买入，当RSI高于超买阈值时卖出
- **参数**: RSI周期、超买阈值、超卖阈值
- **优点**: 捕捉反转机会，适合震荡市场
- **缺点**: 趋势市场中容易过早离场

### MACD策略
- **原理**: 当MACD线上穿信号线时买入，当MACD线下穿信号线时卖出
- **参数**: 快线周期、慢线周期、信号线周期
- **优点**: 结合趋势和动量，信号明确
- **缺点**: 滞后于价格变化

### 布林带策略
- **原理**: 当价格触碰下轨时买入，当价格触碰上轨时卖出
- **参数**: 周期、标准差倍数
- **优点**: 自适应波动率，信号客观
- **缺点**: 强趋势中可能提前止盈

## 回测指标说明

| 指标 | 说明 | 理想值 |
|------|------|--------|
| 夏普比率 | 风险调整后收益 | >1.0 较好，>2.0 优秀 |
| 最大回撤 | 最大亏损幅度 | <20% 较好 |
| 胜率 | 盈利交易占比 | >50% 较好 |
| 盈亏比 | 平均盈利/平均亏损 | >1.5 较好 |
| 总收益率 | 累计收益 | 越高越好 |

## 注意事项
