## 1. 产品概述

Web端形状识别工具，支持用户手绘或上传图像，自动识别几何形状（矩形、圆形、三角形、多边形），提供形状拟合、属性测量（面积、周长）和形状编辑功能。面向设计师、工程师、学生等需要快速识别和测量几何形状的专业人士。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用所有形状识别、测量、编辑功能 |

### 2.2 功能模块

1. **画布工作区**：手绘画布、图像上传、形状识别结果展示
2. **形状识别引擎**：轮廓检测、形状分类、参数拟合
3. **属性测量面板**：面积计算、周长计算、顶点坐标显示
4. **形状编辑器**：顶点拖拽、缩放旋转、颜色样式调整
5. **工具栏**：绘图工具、清除、撤销、导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 主工作台 | 顶部工具栏 | 包含手绘/上传切换、识别按钮、清除/撤销/导出功能 |
| 主工作台 | 中央画布区 | Canvas画布，支持手绘绘图和图像显示 |
| 主工作台 | 右侧属性面板 | 显示识别出的形状列表、属性测量结果、形状编辑工具 |
| 主工作台 | 底部状态栏 | 显示当前操作状态、鼠标坐标、缩放比例 |

## 3. 核心流程

用户手绘形状或上传图像 → 点击识别按钮 → 后端处理图像并识别轮廓 → 形状分类与拟合 → 前端渲染识别结果 → 用户选择形状查看属性/编辑形状 → 导出结果

```mermaid
flowchart LR
    A["用户手绘/上传图像" --> B["点击识别按钮"]
    B --> C["后端图像处理"]
    C --> D["轮廓检测"]
    D --> E["形状分类（矩形/圆形/三角形/多边形"]
    E --> F["参数拟合"]
    F --> G["前端渲染识别结果"]
    G --> H["用户选择形状"]
    H --> I["查看属性（面积、周长）"]
    H --> J["编辑形状（拖拽、缩放、旋转"]
    J --> K["导出结果"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝科技感 (#1E3A5F) 搭配青色高亮 (#00D4FF)
- **辅助色**：形状颜色区分：矩形(#FF6B6B)、圆形(#4ECDC4)、三角形(#FFE66D)、多边形(#95E1D3)
- **按钮样式**：圆角8px，悬停有微妙缩放动画，按压有下沉效果
- **字体**：标题使用 'Space Mono' 等宽字体，正文使用 'Inter' 无衬线字体
- **布局风格**：三栏布局，左侧工具栏居中画布，右侧属性面板，深色主题
- **图标风格**：线性简约风格，统一24px尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|----------|----------|
| 主工作台 | 顶部工具栏 | 深色背景、图标按钮组、分隔线、下拉菜单 |
| 主工作台 | 中央画布区 | 网格背景、Canvas图层、选中高亮、控制点 |
| 主工作台 | 右侧属性面板 | 卡片式形状列表、属性卡片、数值显示、滑块控制 |
| 主工作台 | 底部状态栏 | 坐标显示、缩放滑块、状态提示 |

### 4.3 响应式

桌面端优先设计，支持平板适配，移动端简化为上下布局，属性面板可折叠。

### 4.4 交互动效

- 形状识别完成时有淡入动画
- 选中形状时有脉冲高亮效果
- 拖拽顶点时有实时预览
- 按钮悬停有微妙缩放和阴影变化
- 识别过程有加载动画
