# 汽车油耗预测系统 V3.0

**XGBoost分位数回归 + 加速度传感器融合 + 行程记录 + 异常检测 + 车辆健康

## ✨ V3.0 全新功能

### 📝 1. 行程油耗记录
- 行程记录管理（日期、距离、实际用、平均车速
- 加油记录与里程追踪（加油量、油价、总费用、里程
- 自动计算实际油耗，基于加满油箱算法
- 历史记录统计与趋势分析

### 🎯 2. 实际加油数据校准
- 基于历史加油数据自动校准预测模型
- 校准因子自动计算与应用
- 预测结果自动应用校准因子
- 提供更准确的个性化预测

### ⚠️ 3. 油耗异常检测
- 滑动窗口统计异常检测算法
- Z-Score + 基线偏离检测
- 突然增高行程告警
- 异常严重度分级（中/高）
- 趋势分析与异常处理

### 🔧 4. 车辆健康与故障码分析
- 内置21个常见故障码数据库
- 故障码严重度分级（轻/中/严重）
- 故障码油耗影响估算（3-30%）
- 车辆健康评分系统（0-100分）
- 系统分类（传感器、燃油、点火、排放、电气、变速箱、冷却
- 维护建议与预期节油效果

## ✨ V2.0 升级特性

### 🔥 1. 加速度传感器融合
- 纵向/横向加速度均值和标准差
- 急加速、急刹车、急变道事件识别
- 加减速切换频率、怠速时间占比
- 大油门持续占比、加速度变化率（Jerk）
- 12个传感器衍生特征，更精准识别驾驶行为

### 📊 2. 分位数回归预测区间
- 训练5%、50%、95%三个分位数模型
- 使用Pinball Loss优化分位数预测
- 提供90%置信区间，比传统方法窄约30-50%
- 区间可视化展示，标注上下限和中位数

### 🎯 3. 个性化驾驶行为分析
- 六维驾驶评分：加速习惯、刹车习惯、变道习惯、怠速习惯、巡航习惯、油门效率
- 雷达图可视化展示各维度得分
- 自动识别驾驶弱点，按影响优先级排序
- 估算每个弱点的油耗影响和潜在节油量
- 提供针对性改进建议和预期节油效果

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 生成数据（可选）

数据已预生成，如需重新生成：

```bash
cd data
python generate_data.py
```

### 3. 训练模型（可选）

模型已预训练，如需重新训练：

```bash
python run_training.py
```

### 4. 启动应用

```bash
streamlit run app.py
```

应用将在 http://localhost:8501 启动

## 技术栈

- **模型**: XGBoost Regressor
- **特征工程**: 标准化、标签编码、衍生特征
- **可解释性**: SHAP (SHapley Additive exPlanations)
- **前端**: Streamlit
- **数据处理**: Pandas, NumPy
- **可视化**: Matplotlib

## 特征说明

### 车辆参数
- 车型：轿车/SUV/MPV/皮卡/跑车
- 发动机类型：自然吸气/涡轮增压/混动/插电混动
- 变速箱类型：手动/自动/CVT/双离合
- 排量、整备质量、马力

### 行驶工况
- 路况类型：城市道路/高速公路/乡村公路/山区公路
- 交通状况：畅通/缓行/拥堵/严重拥堵
- 天气状况：晴天/雨天/雪天/雾天
- 环境温度、海拔变化

### 驾驶习惯
- 驾驶风格：温和/标准/激进
- 平均车速、车速波动
- 加速强度、刹车频率
- 定速巡航占比
- 胎压、空调使用
- 乘客人数、行李重量

## 衍生特征

- 功率重量比：马力/整备质量
- 排量马力比：排量/马力
- 负荷指数：(乘客+行李)/整备质量
- 路况复杂度：交通状况*2 + 路况类型
- 驾驶激进度：综合加速、刹车、巡航
- 温度影响：|温度-25|
- 胎压异常：胎压是否在正常范围

## 使用说明

1. 在「油耗预测」标签页调整各项参数
2. 点击「预测油耗」按钮获取结果
3. 切换到「节油建议」查看个性化建议
4. 在「车型对比」页比较不同车型的油耗表现
5. 在「模型解释」页查看SHAP分析结果

## 模型性能

- 训练集 R² > 0.95
- 测试集 R² > 0.90
- 5折交叉验证稳定

## 注意事项

- 本系统基于模拟数据训练，实际使用时请用真实数据微调
- 预测结果仅供参考，实际油耗受多种因素影响
- 建议定期用真实数据更新模型
