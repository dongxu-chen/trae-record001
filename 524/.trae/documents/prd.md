## 1. 产品概述

停车场空位引导系统——基于时序预测与强化学习的智能停车引导平台。通过实时传感器监控各区域车位占用状态，利用历史数据学习预测未来空位变化趋势，结合强化学习动态优化引导策略，帮助驾驶员快速找到最快有空位的停车区域，减少寻位时间和停车场拥堵。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 驾驶员 | 无需注册 | 查看实时空位、接收引导推荐 |
| 管理员 | 密码登录 | 查看历史数据、调整预测参数、监控系统状态 |

### 2.2 功能模块

1. **监控大屏页**：实时停车场地图、各区域空位数、预测趋势、引导推荐
2. **数据分析页**：历史占用率曲线、预测准确率、RL策略效果对比
3. **引导推荐页**：当前最优推荐区域、预计到达时间、置信度评分

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 监控大屏页 | 停车场地图 | SVG地图展示各区域位置，颜色编码空位状态，点击查看详情 |
| 监控大屏页 | 实时空位面板 | 各区域当前空位数、总车位数、占用率，每3秒自动刷新 |
| 监控大屏页 | 预测趋势图 | 未来30分钟各区域空位数时序预测曲线 |
| 监控大屏页 | 引导推荐卡 | RL推荐的最优停车区域、预计步行距离、置信度 |
| 数据分析页 | 历史占用率 | 日/周/月维度占用率曲线，支持区域筛选 |
| 数据分析页 | 预测准确率 | 模型预测值与实际值对比，MAE/RMSE指标 |
| 数据分析页 | 策略效果 | RL引导策略 vs 随机/就近策略的对比分析 |
| 引导推荐页 | 推荐结果 | 当前时刻最优推荐区域列表及详细原因 |
| 引导推荐页 | 模拟驾驶 | 输入入口位置，模拟到达各区域时间及空位概率 |

## 3. 核心流程

用户进入停车场后，系统通过传感器实时采集各区域车位数据。时序预测模型基于历史数据预测未来空位变化。强化学习Agent根据当前状态（各区域空位数、预测趋势、用户位置）选择最优引导区域。前端地图实时展示状态，并向用户推送引导建议。

    "最优区域推荐" --> "前端地图展示"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 (#0F172A) + 科技青 (#06D6A0) + 警示橙 (#FF6B35)
- 按钮风格：圆角矩形，微发光效果，hover时有光晕
- 字体：Orbitron（标题/数据）+ Noto Sans SC（正文）
- 布局风格：暗色科技大屏风格，卡片式模块，网格布局
- 图标风格：线性科技风图标，带发光描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 监控大屏页 | 停车场地图 | SVG地图，区域渐变色填充，空位数气泡，脉冲动画 |
| 监控大屏页 | 实时空位面板 | 环形进度条，数字翻牌动画，状态指示灯 |
| 监控大屏页 | 预测趋势图 | 折线图，预测区间阴影，动态数据点 |
| 监控大屏页 | 引导推荐卡 | 发光边框卡片，箭头指引动画，置信度条 |
| 数据分析页 | 历史占用率 | 面积图，时间段切换按钮，区域多选 |
| 数据分析页 | 策略效果 | 柱状对比图，指标卡片 |

### 4.3 响应式设计

桌面优先设计，支持1920×1080大屏展示模式。平板端简化地图，手机端仅展示推荐列表和关键数据。

### 4.4 地图设计

- SVG矢量停车场平面图
- 5个停车区域（A-E），各有不同容量
- 区域颜色：绿色（空位多）→ 黄色（紧张）→ 红色（已满）
- 区域间通道标注
- 入口/出口标记
