## 1. 产品概述

DepGuard — 微服务依赖版本管理工具，面向DevOps工程师和开发团队，自动扫描微服务架构中各服务依赖的库版本，检测版本冲突、安全漏洞和过时依赖，提供智能升级建议、兼容性评估与批量升级PR创建能力。

- 解决微服务架构下依赖版本碎片化、安全漏洞难发现、升级成本高等痛点
- 目标用户：中大型企业的DevOps团队、SRE工程师、Java微服务开发人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 邀请制 | 管理服务仓库、配置扫描策略、审批批量升级PR |
| 开发者 | GitHub OAuth | 查看依赖报告、发起升级建议、创建批量PR |

### 2.2 功能模块

1. **仪表盘页面**: 全局概览、风险统计、服务健康度、最新扫描结果
2. **服务详情页面**: 单服务依赖树、版本冲突列表、漏洞详情、升级路径
3. **漏洞报告页面**: 全量安全漏洞列表、CVE详情、影响范围、修复版本
4. **升级建议页面**: 智能升级推荐、兼容性矩阵、批量选择、一键创建PR
5. **仓库管理页面**: 添加/移除GitHub仓库、扫描调度、扫描历史

## 3. 核心流程

**扫描流程**: 用户添加GitHub仓库 → 系统克隆仓库 → 解析pom.xml/build.gradle → 提取依赖及版本 → 查询Maven Central/安全数据库 → 生成分析报告 → 展示检测结果

**升级流程**: 用户查看升级建议 → 评估兼容性 → 选择升级项 → 预览PR变更 → 系统创建分支并修改依赖文件 → 通过GitHub API创建PR → 通知用户

```mermaid
flowchart TD
    "A[添加GitHub仓库]" --> "B[触发依赖扫描]"
    "B" --> "C[解析pom.xml/build.gradle]"
    "C" --> "D[提取依赖与版本信息]"
    "D" --> "E[查询最新版本与安全数据库]"
    "E" --> "F[检测冲突/漏洞/过时版本]"
    "F" --> "G[生成分析报告]"
    "G" --> "H[仪表盘展示风险概览]"
    "H" --> "I[用户查看升级建议]"
    "I" --> "J[兼容性评估与批量选择]"
    "J" --> "K[预览PR变更Diff]"
    "K" --> "L[创建分支并修改依赖文件]"
    "L" --> "M[通过GitHub API创建PR]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调: 深青色(#0A2540) + 亮绿色(#00D4AA)强调色，搭配暗色主题
- 辅助色: 漏洞严重性用红(#FF4757)/橙(#FFA502)/黄(#FECA57)/蓝(#54A0FF)四色编码
- 按钮风格: 圆角微凸，主操作按钮带微妙渐变和悬停发光效果
- 字体: 标题使用 JetBrains Mono（代码工具感），正文使用 DM Sans
- 布局风格: 左侧固定导航栏 + 右侧内容区，卡片式模块布局
- 图标风格: 线性图标(Phosphor Icons)，与暗色主题匹配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 风险统计卡片 | 暗色卡片+发光边框，数字用大号JetBrains Mono，趋势箭头动画 |
| 仪表盘 | 服务依赖概览 | 热力图矩阵，色阶从绿到红表示健康度 |
| 仪表盘 | 最近扫描活动 | 左对齐时间线，扫描状态带脉冲动画指示器 |
| 仪表盘 | 严重漏洞告警 | 红色渐变背景卡片，闪烁提醒图标 |
| 服务详情 | 依赖树可视化 | 力导向图/树形图，节点颜色按版本新旧渐变，冲突节点红色高亮 |
| 服务详情 | 版本冲突检测 | 表格行红/黄背景渐变，冲突版本并排对比 |
| 漏洞报告 | 漏洞列表 | 虚拟滚动表格，行悬停展开CVE详情面板 |
| 漏洞报告 | CVE详情面板 | 右侧滑入抽屉，CVSS评分环形进度条 |
| 升级建议 | 兼容性矩阵 | 网格热力图，绿色=兼容，红色=Breaking Change |
| 升级建议 | 批量操作区 | 底部固定操作栏，复选框+计数器+操作按钮 |
| 升级建议 | PR预览 | 代码Diff视图，红绿高亮增删行 |
| 仓库管理 | 仓库列表 | 卡片网格，每张卡片展示仓库信息和扫描状态徽章 |

### 4.3 响应式设计

- 桌面优先设计，支持1440px+宽屏最佳体验
- 平板端(768-1024px): 左侧导航折叠为图标模式，卡片改为单列
- 移动端(<768px): 底部Tab导航，关键信息优先展示，复杂图表提供简化视图

### 4.4 动效设计

- 页面加载: 数据卡片交错渐入(stagger animation)，延迟50ms递增
- 扫描中状态: 脉冲动画圆形指示器 + 进度条
- 漏洞告警: 高危漏洞卡片边框红色脉冲
- PR创建: 成功后绿色对勾动画 + Toast通知
- 依赖树: 节点展开/折叠带弹性动画
