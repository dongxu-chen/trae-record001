# 数据脱敏预览组件

一个功能完整的Web端数据脱敏预览组件，支持配置脱敏规则并实时预览脱敏效果。

## 功能特性

- 🔒 **5种脱敏方式**：掩码、替换、哈希、截断、打乱
- 📱 **预设规则**：手机号、身份证、邮箱、姓名、地址
- ⚙️ **字段级别配置**：每个字段可独立配置脱敏方式和参数
- 👁️ **实时预览**：输入数据后立即查看脱敏效果
- 📊 **批量处理**：支持JSON格式的批量数据处理
- 🎨 **精美界面**：现代化渐变设计，响应式布局

## 技术栈

**前端**：
- React 18 + Vite
- 纯CSS样式（无额外UI库依赖）

**后端**：
- Node.js + Express
- 提供RESTful API接口

## 脱敏方式说明

### 1. 自适应掩码脱敏 (Mask)
按输入长度动态调整掩码位置和长度
- 可自定义开头保留字符数（keepStart）
- 可自定义结尾保留字符数（keepEnd）
- 可自定义掩码字符（默认*）
- 自适应示例：
  - 手机号 `13800138000` → `138****8000`（首3尾4）
  - 身份证 `110101199001011234` → `110101********1234`（首6尾4）
  - 邮箱 `example@email.com` → `ex****@email.com`（首2尾0）
  - 自适应模式根据字符串长度智能调整

### 2. 替换脱敏 (Replace)
自定义替换字符
- 可设置替换字符（默认*）
- 支持多种模式：手机号、身份证、邮箱、自适应、全部掩码

### 3. 一致性哈希脱敏 (Hash)
不可逆加密，支持盐值配置
- 支持算法：MD5、SHA-1、SHA-256
- 支持自定义盐值（salt）
- 相同输入 + 相同盐值 = 相同输出（一致性保证）

### 4. 截断脱敏 (Truncate)
截断超出长度的内容
- 可设置最大长度
- 超出部分显示...

### 5. 打乱脱敏 (Shuffle)
随机打乱字符顺序

## 表格化批量配置功能

- ✅ **全选/取消全选**：一键选择所有字段
- ✅ **批量启用/禁用**：对选中字段批量操作
- ✅ **批量配置**：为选中字段统一设置脱敏方式和参数
- ✅ **行内编辑**：直接在表格中配置每个字段的参数
- ✅ **可视化状态**：清晰显示每个字段的启用状态和脱敏方式

## API接口

### POST /api/mask
单条数据脱敏

**请求体**：
```json
{
  "data": {
    "phone": "13800138000",
    "email": "example@email.com"
  },
  "rules": {
    "phone": {
      "enabled": true,
      "method": "mask",
      "pattern": "phone"
    }
  }
}
```

### POST /api/mask/batch
批量数据脱敏

### GET /api/rules/default
获取默认规则配置

### GET /api/methods
获取所有脱敏方式

### GET /api/patterns
获取所有掩码模式

## 使用说明

1. **开启脱敏规则**：在左侧卡片中点击开关启用需要脱敏的字段
2. **配置脱敏方式**：为每个字段选择合适的脱敏方式和参数
3. **输入测试数据**：在右侧输入需要脱敏的数据
4. **查看效果**：实时查看脱敏前后的对比结果
5. **批量处理**：切换到批量数据标签，输入JSON数组进行批量处理
