# 漫画阅读器 Web 应用

基于 Vue 3 + Pixi.js 构建的现代化漫画阅读器。

## 功能特性

### ✅ 已实现

1. **双页模式** - 同时显示两页漫画，模拟实体书阅读体验
2. **卷轴模式** - 纵向连续滚动阅读，适合长条形屏幕
3. **缩放功能** - 支持 50% - 300% 缩放，鼠标滚轮控制
4. **书签功能** - 一键添加/移除书签，快速跳转到标记页面
5. **预加载机制** - 智能预加载前后3页图片，提升阅读流畅度
6. **拖拽平移** - 按住鼠标拖动查看放大后的图片
7. **点击翻页** - 点击屏幕左右两侧快速翻页
8. **响应式设计** - 自适应窗口大小变化

## 技术栈

- **Vue 3** - 使用 Composition API
- **Pixi.js 7** - WebGL 2D 渲染引擎
- **Vite** - 现代化前端构建工具

## 使用说明

### 阅读模式切换

- 点击顶部「📖 双页」/「📜 卷轴」按钮切换阅读模式

### 翻页操作

- **点击左侧 1/3 区域**：上一页
- **点击右侧 1/3 区域**：下一页
- **底部按钮**：使用「上一页」「下一页」按钮
- **页码输入**：直接输入页码跳转到指定页面

### 缩放控制

- **鼠标滚轮**：向上放大，向下缩小
- **按钮控制**：使用底部的 +/- 按钮精确控制
- **重置缩放**：点击 ↺ 按钮恢复原始大小

### 书签功能

- **添加书签**：点击 ⭐ 按钮标记当前页
- **移除书签**：再次点击 ⭐ 按钮取消标记
- **跳转书签**：点击书签列表中的页码直接跳转

### 拖拽平移

当图片放大超出屏幕时，按住鼠标拖动可以平移查看图片。

## 自定义漫画图片

在 `ComicReader.vue` 中修改 `demoImages` 数组：

```javascript
const demoImages = [
  '你的图片URL1',
  '你的图片URL2',
  // ...
]
```

## 预加载配置

在 `src/composables/usePreload.js` 中可以调整预加载页数：

```javascript
const PRELOAD_COUNT = 3  // 预加载前后各3页
```
