# 股票市场冲击成本模型

一个基于订单簿数据分析的市场冲击成本预测和最优执行策略工具，使用 Python + 机器学习 + Streamlit 实现。

## 功能特性

### 1. 订单簿可视化
- 实时模拟订单簿数据
- 订单簿分布直方图
- 累计深度曲线
- 多档位订单数据展示

### 2. 市场冲击成本分析
- 滑点-交易量冲击曲线
- 平均执行价格预测
- 逐档位成交明细
- 买入/卖出双向冲击分析

### 3. 机器学习预测模型
- 梯度提升树(GBDT)模型
- 12个特征工程（深度比例、价差、斜率、不平衡度等）
- 模型性能指标展示
- 特征重要性分析
- 多模型对比（实际计算 vs ML预测 vs 平方根模型）

### 4. 最优拆单策略
- TWAP（时间加权平均价格）策略
- VWAP（成交量加权平均价格）策略
- 拆单数量优化曲线
- 策略对比和推荐
- 成本节省分析

## 项目结构

```
├── app.py                  # Streamlit主应用
├── order_book.py           # 订单簿模拟和冲击计算
├── impact_models.py        # 冲击模型和最优执行
├── requirements.txt        # Python依赖
├── run.bat                 # Windows启动脚本
└── README.md               # 说明文档
```

## 快速开始

### 方式一：使用启动脚本（Windows）
双击运行 `run.bat`

### 方式二：手动启动

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 启动应用：
```bash
streamlit run app.py
```

3. 浏览器访问：http://localhost:8501

## 使用说明

### 左侧参数面板

1. **订单簿参数**
   - 中间价格：股票当前价格
   - 基础深度：最优档位挂单量基准
   - 深度衰减：后续档位深度衰减系数
   - 买卖价差：买卖一档之间的价差
   - 订单簿档位：显示的档位数量

2. **交易参数**
   - 交易方向：买入/卖出
   - 总交易量：需要执行的总股数

3. **模型参数**
   - 风险厌恶系数：影响策略选择
   - 最大拆单数：优化时考虑的最大拆单数量

### 功能标签页

1. **订单簿可视化**：查看订单簿深度分布和累计深度曲线

2. **冲击成本曲线**：分析不同交易量下的滑点情况

3. **ML预测模型**：查看机器学习模型性能和预测结果

4. **最优拆单策略**：获取智能拆单建议和优化曲线

5. **执行策略对比**：详细对比不同执行策略的效果

## 核心算法

### 市场冲击计算
- 基于订单簿深度的逐档位撮合
- 考虑价格滑点的累计成本计算

### 机器学习模型
- 特征：深度比例、价差、订单簿斜率、不平衡度等
- 算法：Gradient Boosting Regression
- 自动生成训练样本进行训练

### 最优执行策略
- TWAP：平均分配订单数量
- VWAP：根据订单簿深度加权分配
- 自动搜索最优拆单数量

## 技术栈

- **前端界面**：Streamlit
- **数据处理**：Pandas, NumPy
- **可视化**：Plotly
- **机器学习**：Scikit-learn
- **数值计算**：SciPy
