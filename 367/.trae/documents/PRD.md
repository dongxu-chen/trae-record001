# 知识图谱可视化工具 PRD

## 1. 产品概述
一款面向科研、情报与企业知识管理场景的 Web 端知识图谱可视化与分析工具。通过导入三元组（实体-关系-实体）数据，自动完成图布局与渲染，并提供搜索筛选、最短路径查询、实体详情下钻等核心能力。

- 目标用户：知识工程研究员、数据分析师、风控/反欺诈团队、业务洞察人员
- 价值：将结构化三元组数据转化为可交互的可视化网络，帮助用户快速发现关联、定位关键实体、追溯实体间路径

## 2. 核心功能

### 2.1 功能模块
1. **数据导入**：支持粘贴/上传三元组数据（JSON/TSV），解析后入库
2. **图谱画布**：D3 力导向布局、缩放平移、节点拖拽、悬停高亮
3. **搜索与筛选**：实体名/关系类型模糊搜索，按类型筛选，动态高亮
4. **路径查询**：输入起点/终点实体，返回最短路径并高亮
5. **实体详情**：点击节点弹出侧边面板，展示属性/关系列表/关联邻居

### 2.2 页面详情
| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 主工作台 | 顶部工具栏 | 数据导入、搜索框、筛选按钮、路径查询入口 |
| 主工作台 | 图谱画布 | D3 SVG 渲染，力导向自动布局，节点/边/标签 |
| 主工作台 | 详情侧边栏 | 实体属性、关系列表、邻居导航 |
| 主工作台 | 底部状态栏 | 节点/边统计、布局状态 |

## 3. 核心流程
用户打开工具 → 导入三元组数据 → 系统解析并自动布局渲染 → 用户在画布浏览/缩放/悬停 → 通过搜索或点击节点深入分析 → 发起路径查询查看最短路径 → 在详情面板获取实体全量信息

```mermaid

    "A[用户进入应用]" --> "B[导入三元组数据]"

    "F" --> "G[搜索/筛选]"

    "F" --> "I[点击节点看详情]"
```

## 4. 界面设计

### 4.1 设计风格
- **整体风格**：深色赛博风 + 数据可视化质感
- **主色**：`#0a0e1a`（背景）、`#111827`（面板）、`#06b6d4`（青色强调）
- **辅色**：`#8b5cf6`（紫）、`#f472b6`（粉）、`#10b981`（绿）
- **字体**：`JetBrains Mono` 标题 / `Inter` 正文
- **按钮**：圆角、微发光、悬停上浮
- **布局**：三栏（左工具栏、中画布、右详情）
- **动效**：节点进入淡入缩放、路径查询逐段流动、侧栏滑入

### 4.2 页面设计
| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 主工作台 | 工具栏 | 深色卡片、青色按钮、发光搜索框 |
| 主工作台 | 画布 | 深星空背景、节点渐变光晕、边带方向箭头 |
| 主工作台 | 详情栏 | 半透明毛玻璃、分类分区、可折叠 |

### 4.3 响应式
桌面优先（≥1200px），≥768px 自动折叠侧栏，移动端仅保留核心图谱视图。
