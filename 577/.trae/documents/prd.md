## 1. 产品概述

Web端数据抽样工具——面向数据分析师和开发者的专业抽样平台，支持从大文件中按多种策略（随机、分层、系统抽样）进行数据抽样，提供实时预览与比例调节能力，解决大数据场景下快速获取代表性样本的需求。

- 核心问题：大文件（GB级别）无法一次性加载到浏览器，需要分块读取与高效抽样算法
- 目标用户：数据分析师、数据工程师、科研人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 上传文件、配置抽样、预览与导出结果 |

### 2.2 功能模块

1. **数据抽样工作台**：文件上传、格式识别、抽样配置、样本预览、结果导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据抽样工作台 | 文件上传区 | 拖拽或点击上传CSV/JSON/Parquet文件，自动识别格式与文件大小，显示文件元信息（行数、列数、字段类型） |
| 数据抽样工作台 | 抽样配置面板 | 选择抽样方法（随机/分层/系统），设置抽样比例(1%-100%)，分层抽样可选分层字段，系统抽样可设置间隔步长 |
| 数据抽样工作台 | 原始数据预览 | 分页预览原始文件前N行数据，支持列排序与字段筛选 |
| 数据抽样工作台 | 样本数据预览 | 展示抽样结果数据，统计信息（样本量、各层占比），支持数据表格展示 |
| 数据抽样工作台 | 抽样统计仪表盘 | 显示抽样比例、样本量、各分层分布柱状图、数据质量指标 |
| 数据抽样工作台 | 结果导出 | 将样本数据导出为CSV/JSON格式 |

## 3. 核心流程

用户上传数据文件 → 系统分块读取并解析文件 → 自动识别格式与字段 → 用户配置抽样参数 → Web Worker执行抽样算法 → 返回样本数据 → 预览与统计展示 → 导出结果

```mermaid
    "J" --> "K[返回样本数据]"
    "K" --> "L[预览与统计展示]"
    "L" --> "M[导出结果]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰(#1e293b) + 亮青色(#06b6d4)作为强调色，辅以暖橙色(#f97316)作为操作反馈
- 按钮风格：圆角矩形(8px)，带微妙阴影与hover渐变效果
- 字体：JetBrains Mono用于数据表格，Source Sans 3用于UI文本
- 布局风格：左侧配置面板 + 右侧数据预览区的双栏布局，顶部状态栏
- 图标风格：Lucide线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据抽样工作台 | 文件上传区 | 虚线拖拽区域，文件图标，格式标签(CSV/JSON/Parquet)，进度条，文件元信息卡片 |
| 数据抽样工作台 | 抽样配置面板 | 抽样方法选择卡片组，比例滑块，分层字段下拉选择，步长输入框，执行按钮 |
| 数据抽样工作台 | 原始数据预览 | 可滚动数据表格，分页控件，列头排序指示器，字段类型标签 |
| 数据抽样工作台 | 样本数据预览 | 高亮样本行数据表格，样本量统计，分布柱状图 |
| 数据抽样工作台 | 抽样统计仪表盘 | 圆环图(抽样比例)，柱状图(分层分布)，统计卡片(样本量/原始量/比例) |
| 数据抽样工作台 | 结果导出 | 导出格式选择，下载按钮 |

### 4.3 响应式设计

- 桌面优先设计，双栏布局（配置+预览）
- 平板端折叠为单栏，配置面板可收起
- 移动端全屏单栏，底部操作栏
